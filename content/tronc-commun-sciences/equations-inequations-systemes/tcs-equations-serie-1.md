Quatre exercices sur la première partie du cours.

:::exercice Équations
Résoudre dans $\mathbb{R}$ :

1. $3(x - 2) - 2(x + 1) = 4$
2. $(x + 4)(2x - 6) = 0$
3. $x^2 - 9 = (x - 3)(2x + 1)$
4. $\dfrac{2x + 1}{x - 3} = 0$

:::corrige
1. $3x - 6 - 2x - 2 = 4 \iff x = 12$.
2. $x = -4$ ou $x = 3$.
3. $(x - 3)(x + 3 - 2x - 1) = 0 \iff (x - 3)(2 - x) = 0$ : $x = 3$ ou $x = 2$.
4. $2x + 1 = 0$ et $x \neq 3$ : $x = -\frac{1}{2}$.
:::
:::

:::exercice Inéquations
Résoudre dans $\mathbb{R}$ :

1. $5 - 2x \geq 3x + 15$
2. $(x + 1)(x - 4) < 0$
3. $\dfrac{x - 2}{x + 1} \geq 0$

:::corrige
1. $-5x \geq 10 \iff x \leq -2$ : $S = ]-\infty ; -2]$.
2. Le produit est négatif entre les racines $-1$ et $4$ : $S = ]-1 ; 4[$.
3. Même signe pour $x < -1$ ou $x > 2$, nul en $2$, interdit en $-1$ : $S = ]-\infty ; -1[ \cup [2 ; +\infty[$.
:::
:::

:::exercice Second degré
Résoudre dans $\mathbb{R}$ :

1. $x^2 + 2x - 15 = 0$
2. $9x^2 - 6x + 1 = 0$
3. $2x^2 + x + 3 = 0$

:::corrige
1. $\Delta = 4 + 60 = 64$ : $x = \frac{-2 + 8}{2} = 3$ ou $x = \frac{-2 - 8}{2} = -5$.
2. $\Delta = 36 - 36 = 0$ : $x = \frac{6}{18} = \frac{1}{3}$.
3. $\Delta = 1 - 24 < 0$ : pas de solution.
:::
:::

:::exercice Inéquations du second degré
Résoudre dans $\mathbb{R}$ :

1. $x^2 - 5x + 4 \leq 0$
2. $-x^2 + 2x + 3 > 0$
3. $x^2 + x + 1 \geq 0$

:::corrige
1. Racines $1$ et $4$, $a > 0$ : $S = [1 ; 4]$.
2. Racines $-1$ et $3$, $a < 0$ : positif entre les racines, $S = ]-1 ; 3[$.
3. $\Delta = -3 < 0$, $a > 0$ : $S = \mathbb{R}$.
:::
:::
