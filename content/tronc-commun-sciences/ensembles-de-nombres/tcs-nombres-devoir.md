Durée : une heure.

:::exercice Exercice 1 (6 points) : ensembles
1. Compléter par $\in$ ou $\notin$ : $-4 \ldots \mathbb{N}$ ; $\frac{3}{5} \ldots \mathbb{D}$ ; $\frac{1}{6} \ldots \mathbb{D}$ ; $\sqrt{16} \ldots \mathbb{Z}$. (2 pts)
2. Écrire $x = 2{,}363636\ldots$ sous forme de fraction irréductible. (2 pts)
3. Montrer que $\frac{1}{6}$ n’est pas décimal. (2 pts)

:::corrige
1. $-4 \notin \mathbb{N}$ ; $\frac{3}{5} = 0{,}6 \in \mathbb{D}$ ; $\frac{1}{6} \notin \mathbb{D}$ ; $\sqrt{16} = 4 \in \mathbb{Z}$.
2. $100x - x = 236 - 2 = 234$, donc $x = \frac{234}{99} = \frac{26}{11}$.
3. Si $\frac{1}{6} = \frac{a}{10^n}$, alors $10^n = 6a$, et $3$ diviserait $10^n = 2^n \times 5^n$ : impossible.
:::
:::

:::exercice Exercice 2 (6 points) : puissances et racines
1. Simplifier $A = \dfrac{2^{10} \times 5^{8}}{10^{7}}$. (2 pts)
2. Simplifier $B = 3\sqrt{12} - \sqrt{75} + \sqrt{27}$. (2 pts)
3. Écrire $C = \dfrac{4}{\sqrt{7} - \sqrt{3}}$ sans racine au dénominateur. (2 pts)

:::corrige
1. $A = \frac{2^{10} \times 5^8}{2^7 \times 5^7} = 2^3 \times 5 = 40$.
2. $6\sqrt{3} - 5\sqrt{3} + 3\sqrt{3} = 4\sqrt{3}$.
3. $C = \frac{4\left(\sqrt{7} + \sqrt{3}\right)}{7 - 3} = \sqrt{7} + \sqrt{3}$.
:::
:::

:::exercice Exercice 3 (8 points) : identités remarquables
1. Développer $(2x + 1)^3$. (3 pts)
2. Factoriser $8x^3 - 1$. (2 pts)
3. Factoriser $E = (x - 1)^2 - 4(x + 2)^2$. (3 pts)

:::corrige
1. $8x^3 + 12x^2 + 6x + 1$.
2. $(2x)^3 - 1^3 = (2x - 1)(4x^2 + 2x + 1)$.
3. $E = (x - 1)^2 - (2x + 4)^2 = (x - 1 - 2x - 4)(x - 1 + 2x + 4) = (-x - 5)(3x + 3) = -3(x + 5)(x + 1)$.
:::
:::
