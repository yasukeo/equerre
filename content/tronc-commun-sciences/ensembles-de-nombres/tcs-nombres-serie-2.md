Quatre exercices sur la deuxième partie du cours.

:::exercice Puissances
Simplifier :

1. $A = \dfrac{3^5 \times 9^2}{27^3}$
2. $B = \dfrac{(2^3)^2 \times 2^{-4}}{4}$
3. Donner l’écriture scientifique de $C = \dfrac{0{,}000\,6 \times 5 \times 10^{8}}{1{,}5 \times 10^{-2}}$.

:::corrige
1. $A = \frac{3^5 \times 3^4}{3^9} = 1$.
2. $B = \frac{2^6 \times 2^{-4}}{2^2} = 2^0 = 1$.
3. $C = \frac{6 \times 10^{-4} \times 5 \times 10^8}{1{,}5 \times 10^{-2}} = \frac{30 \times 10^4}{1{,}5 \times 10^{-2}} = 20 \times 10^6 = 2 \times 10^7$.
:::
:::

:::exercice Racines carrées
Écrire sous la forme $a\sqrt{b}$, avec $b$ entier le plus petit possible :

1. $\sqrt{72}$
2. $\sqrt{20} - 3\sqrt{45} + \sqrt{80}$
3. $\sqrt{8} \times \sqrt{18}$ (donner un entier)

:::corrige
1. $\sqrt{36 \times 2} = 6\sqrt{2}$.
2. $2\sqrt{5} - 9\sqrt{5} + 4\sqrt{5} = -3\sqrt{5}$.
3. $\sqrt{144} = 12$.
:::
:::

:::exercice Dénominateurs
Écrire sans racine au dénominateur :

1. $\dfrac{5}{\sqrt{10}}$
2. $\dfrac{2}{\sqrt{5} + 1}$
3. $\dfrac{\sqrt{2} + 1}{\sqrt{2} - 1}$

:::corrige
1. $\frac{5\sqrt{10}}{10} = \frac{\sqrt{10}}{2}$.
2. $\frac{2\left(\sqrt{5} - 1\right)}{5 - 1} = \frac{\sqrt{5} - 1}{2}$.
3. $\frac{\left(\sqrt{2} + 1\right)^2}{2 - 1} = 2 + 2\sqrt{2} + 1 = 3 + 2\sqrt{2}$.
:::
:::

:::exercice Identités remarquables
1. Développer $(x - 3)^3$ et $\left(1 + 2\sqrt{2}\right)^2$.
2. Factoriser $4x^2 - 25$, $x^3 + 27$ et $x^2 + 6x + 9 - y^2$.

:::corrige
1. $(x - 3)^3 = x^3 - 9x^2 + 27x - 27$ ; $\left(1 + 2\sqrt{2}\right)^2 = 1 + 4\sqrt{2} + 8 = 9 + 4\sqrt{2}$.
2. $4x^2 - 25 = (2x - 5)(2x + 5)$ ; $x^3 + 27 = (x + 3)(x^2 - 3x + 9)$ ; $x^2 + 6x + 9 - y^2 = (x + 3)^2 - y^2 = (x + 3 - y)(x + 3 + y)$.
:::
:::
