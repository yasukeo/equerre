## Définitions

:::propriete
- Translation : $\overrightarrow{MM'} = \vec{u}$ ; $M'(x + a ; y + b)$.
- Symétrie centrale : $\Omega$ milieu de $[MM']$ ; $M'(2a - x ; 2b - y)$.
- Symétrie axiale : l’axe est la médiatrice de $[MM']$.
- Homothétie : $\overrightarrow{\Omega M'} = k\overrightarrow{\Omega M}$ ; $M'(a + k(x - a) ; b + k(y - b))$.
:::

## Propriétés

:::propriete
- Translation et symétries conservent les distances, l’alignement, le parallélisme, le milieu et les angles.
- Homothétie : $\overrightarrow{A'B'} = k\overrightarrow{AB}$ ; longueurs $\times |k|$, aires $\times k^2$ ; image d’une droite parallèle ; cercle de rayon $|k|r$.
:::

:::attention
Pour trouver le centre et le rapport d’une homothétie qui envoie $A$ sur $A'$ et $B$ sur $B'$ : $k$ vient de $\overrightarrow{A'B'} = k\overrightarrow{AB}$, puis $\Omega$ de $\overrightarrow{\Omega A'} = k\overrightarrow{\Omega A}$.
:::
