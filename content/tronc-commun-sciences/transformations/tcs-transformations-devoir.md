Durée : une heure.

:::exercice Exercice 1 (6 points) : en coordonnées
1. Image de $A(4 ; 1)$ par la translation de vecteur $\vec{u}(-3 ; 2)$. (2 pts)
2. Image de $B(5 ; 3)$ par la symétrie de centre $\Omega(2 ; -1)$. (2 pts)
3. Image de $C(1 ; -3)$ par l’homothétie de centre $O$ et de rapport $-2$. (2 pts)

:::corrige
1. $(1 ; 3)$.
2. $(4 - 5 ; -2 - 3) = (-1 ; -5)$.
3. $(-2 ; 6)$.
:::
:::

:::exercice Exercice 2 (7 points) : dans un triangle
Soit $ABC$ un triangle, $I$ le milieu de $[BC]$, et $D$ l’image de $A$ par la symétrie de centre $I$.

1. Montrer que $ABDC$ est un parallélogramme. (3 pts)
2. Quelle est l’image de $C$ par la translation de vecteur $\overrightarrow{AB}$ ? (2 pts)
3. Par quelle homothétie de centre $A$ le point $I$ a-t-il pour image $D$ ? (2 pts)

:::corrige
1. $I$ est le milieu de $[AD]$ et de $[BC]$ : les diagonales de $ABDC$ ont le même milieu, c’est un parallélogramme.
2. Dans le parallélogramme $ABDC$, $\overrightarrow{CD} = \overrightarrow{AB}$ : l’image de $C$ est $D$.
3. $\overrightarrow{AD} = 2\overrightarrow{AI}$ : $h(A, 2)$.
:::
:::

:::exercice Exercice 3 (7 points) : homothétie
1. Une homothétie de rapport $-3$ transforme un cercle de rayon $2$ cm. Quel est le rayon de l’image ? (2 pts)
2. Elle transforme un triangle d’aire $4$ cm². Quelle est l’aire de l’image ? (2 pts)
3. Une homothétie envoie $A(0 ; 1)$ sur $A'(2 ; 5)$ et $B(1 ; 0)$ sur $B'(5 ; 2)$. Trouver son rapport et son centre. (3 pts)

:::corrige
1. $3 \times 2 = 6$ cm.
2. $9 \times 4 = 36$ cm².
3. $\overrightarrow{AB}(1 ; -1)$ et $\overrightarrow{A'B'}(3 ; -3)$ : $k = 3$. $A' - \Omega = 3(A - \Omega)$ donne $\Omega = \frac{3A - A'}{2} = \left(\frac{0 - 2}{2} ; \frac{3 - 5}{2}\right) = (-1 ; -1)$. Vérification avec $B$ : $\frac{3B - B'}{2} = (-1 ; -1)$.
:::
:::
