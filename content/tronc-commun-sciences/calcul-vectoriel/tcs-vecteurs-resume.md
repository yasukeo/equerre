## Somme

:::propriete
- $\overrightarrow{AB} = \overrightarrow{DC} \iff ABCD$ parallélogramme.
- Chasles : $\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$. Parallélogramme : $\overrightarrow{AB} + \overrightarrow{AD} = \overrightarrow{AC}$.
- $I$ milieu de $[AB] \iff \overrightarrow{IA} + \overrightarrow{IB} = \vec{0}$ ; alors $\overrightarrow{MA} + \overrightarrow{MB} = 2\overrightarrow{MI}$.
:::

## Colinéarité

:::propriete
- $\vec{v} = k\vec{u}$ : même direction ; sens selon le signe de $k$ ; longueur $|k|\,\|\vec{u}\|$.
- $(AB) \parallel (CD) \iff \overrightarrow{AB}$ et $\overrightarrow{CD}$ colinéaires.
- $A$, $B$, $C$ alignés $\iff \overrightarrow{AB}$ et $\overrightarrow{AC}$ colinéaires.
- Centre de gravité : $\overrightarrow{GA} + \overrightarrow{GB} + \overrightarrow{GC} = \vec{0}$, $\overrightarrow{AG} = \frac{2}{3}\overrightarrow{AI}$.
:::

:::attention
Chasles s’applique aux vecteurs, pas aux longueurs.
:::
