## Propriétés générales

:::propriete
- $D_f$ : pas de dénominateur nul, pas de nombre négatif sous une racine.
- Paire : $f(-x) = f(x)$ ; impaire : $f(-x) = -f(x)$ ; sur un ensemble symétrique.
- $T = \frac{f(x_1) - f(x_2)}{x_1 - x_2}$ : $T > 0$ sur $I$, croissante ; $T < 0$, décroissante.
:::

## Courbes de référence

:::propriete
- $ax^2 + bx + c = a(x - \alpha)^2 + \beta$ : parabole de sommet $(\alpha ; \beta)$, $\alpha = -\frac{b}{2a}$.
- $\frac{ax + b}{cx + d} = \beta + \frac{k}{x - \alpha}$ : hyperbole de centre $(\alpha ; \beta)$, asymptotes $x = \alpha$ et $y = \beta$ ; décroissante sur chaque intervalle si $k > 0$, croissante si $k < 0$.
:::

:::attention
Deux fonctions égales doivent d’abord avoir le même ensemble de définition.
:::
