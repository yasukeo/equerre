Durée : une heure.

:::exercice Exercice 1 (7 points) : équations
Résoudre dans $\mathbb{R}$ :

1. $\cos x = \frac{\sqrt{2}}{2}$ (2 pts)
2. $\sin x = -\frac{\sqrt{3}}{2}$ (2 pts)
3. $\tan 2x = 1$ (3 pts)

:::corrige
1. $x = \frac{\pi}{4} + 2k\pi$ ou $x = -\frac{\pi}{4} + 2k\pi$.
2. $\sin x = \sin\left(-\frac{\pi}{3}\right)$ : $x = -\frac{\pi}{3} + 2k\pi$ ou $x = \frac{4\pi}{3} + 2k\pi$.
3. $2x = \frac{\pi}{4} + k\pi$, donc $x = \frac{\pi}{8} + \frac{k\pi}{2}$.
:::
:::

:::exercice Exercice 2 (6 points) : dans un intervalle
1. Résoudre $\cos 2x = 0$ dans $[0 ; \pi]$. (3 pts)
2. Résoudre $2\sin^2 x + \sin x - 1 = 0$ dans $[0 ; 2\pi[$. (3 pts)

:::corrige
1. $2x = \frac{\pi}{2} + k\pi$, donc $x = \frac{\pi}{4} + \frac{k\pi}{2}$ : dans $[0 ; \pi]$, $\frac{\pi}{4}$ et $\frac{3\pi}{4}$.
2. $2X^2 + X - 1 = (2X - 1)(X + 1)$ : $\sin x = \frac{1}{2}$, soit $\frac{\pi}{6}$ ou $\frac{5\pi}{6}$, ou $\sin x = -1$, soit $\frac{3\pi}{2}$.
:::
:::

:::exercice Exercice 3 (7 points) : inéquations
1. Résoudre $\cos x \leq -\frac{1}{2}$ sur $]-\pi ; \pi]$. (3 pts)
2. Résoudre $\sin x \geq \frac{\sqrt{2}}{2}$ sur $[0 ; 2\pi[$. (2 pts)
3. Résoudre $\tan x \geq 0$ sur $\left]-\frac{\pi}{2} ; \frac{\pi}{2}\right[$. (2 pts)

:::corrige
1. $\cos x = -\frac{1}{2}$ en $\pm\frac{2\pi}{3}$ ; l’abscisse est plus petite sur l’arc de gauche : $S = \left]-\pi ; -\frac{2\pi}{3}\right] \cup \left[\frac{2\pi}{3} ; \pi\right]$.
2. $\sin x = \frac{\sqrt{2}}{2}$ en $\frac{\pi}{4}$ et $\frac{3\pi}{4}$ : $S = \left[\frac{\pi}{4} ; \frac{3\pi}{4}\right]$.
3. $S = \left[0 ; \frac{\pi}{2}\right[$.
:::
:::
