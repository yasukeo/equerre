## Équations

:::propriete
- $\cos x = \cos \alpha \iff x = \pm\alpha + 2k\pi$.
- $\sin x = \sin \alpha \iff x = \alpha + 2k\pi$ ou $x = \pi - \alpha + 2k\pi$.
- $\tan x = \tan \alpha \iff x = \alpha + k\pi$.
- $\cos x = a$ ou $\sin x = a$ avec $|a| > 1$ : aucune solution.
:::

## Méthodes

- Dans un intervalle : on donne des valeurs à $k$ et on garde les solutions qui y sont.
- $\cos(ax + b) = \cos \theta$ : on résout pour $ax + b$, puis on divise.
- Second degré : on pose $X = \cos x$ ou $X = \sin x$, avec $-1 \leq X \leq 1$.
- Inéquation : on résout l’équation, on place les points sur le cercle et on lit l’arc (abscisse pour $\cos$, ordonnée pour $\sin$).

:::attention
Dans $\sin x = \sin \alpha$, la seconde famille est $\pi - \alpha$, et non $-\alpha$.
:::
