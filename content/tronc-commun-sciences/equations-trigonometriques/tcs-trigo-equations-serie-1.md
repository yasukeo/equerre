Quatre exercices sur la première partie du cours.

:::exercice Équations de base
Résoudre dans $\mathbb{R}$, puis donner les solutions dans $]-\pi ; \pi]$ :

1. $\cos x = -\frac{\sqrt{3}}{2}$
2. $\sin x = \frac{1}{2}$
3. $\tan x = -1$
4. $\cos x = \frac{3}{2}$

:::corrige
1. $\cos x = \cos \frac{5\pi}{6}$ : $x = \pm\frac{5\pi}{6} + 2k\pi$ ; dans $]-\pi ; \pi]$ : $-\frac{5\pi}{6}$ et $\frac{5\pi}{6}$.
2. $x = \frac{\pi}{6} + 2k\pi$ ou $x = \frac{5\pi}{6} + 2k\pi$ ; dans $]-\pi ; \pi]$ : $\frac{\pi}{6}$ et $\frac{5\pi}{6}$.
3. $\tan x = \tan\left(-\frac{\pi}{4}\right)$ : $x = -\frac{\pi}{4} + k\pi$ ; dans $]-\pi ; \pi]$ : $-\frac{\pi}{4}$ et $\frac{3\pi}{4}$.
4. $\frac{3}{2} > 1$ : aucune solution.
:::
:::

:::exercice Avec ax + b
Résoudre dans $\mathbb{R}$ :

1. $\sin 2x = \frac{\sqrt{3}}{2}$
2. $\cos\left(x - \frac{\pi}{4}\right) = 0$
3. $\sin 3x = \sin x$

:::corrige
1. $2x = \frac{\pi}{3} + 2k\pi$ ou $2x = \frac{2\pi}{3} + 2k\pi$ : $x = \frac{\pi}{6} + k\pi$ ou $x = \frac{\pi}{3} + k\pi$.
2. $\cos\left(x - \frac{\pi}{4}\right) = \cos \frac{\pi}{2}$ : $x - \frac{\pi}{4} = \pm\frac{\pi}{2} + 2k\pi$, soit $x = \frac{3\pi}{4} + 2k\pi$ ou $x = -\frac{\pi}{4} + 2k\pi$, c’est-à-dire $x = \frac{3\pi}{4} + k\pi$.
3. $3x = x + 2k\pi$ ou $3x = \pi - x + 2k\pi$ : $x = k\pi$ ou $x = \frac{\pi}{4} + \frac{k\pi}{2}$.
:::
:::

:::exercice Dans un intervalle
Résoudre dans $[0 ; 2\pi[$ :

1. $\cos 2x = -\frac{1}{2}$
2. $\tan x = \frac{\sqrt{3}}{3}$

:::corrige
1. $2x = \pm\frac{2\pi}{3} + 2k\pi$, donc $x = \pm\frac{\pi}{3} + k\pi$ : $\frac{\pi}{3}$, $\frac{2\pi}{3}$, $\frac{4\pi}{3}$ et $\frac{5\pi}{3}$.
2. $x = \frac{\pi}{6} + k\pi$ : $\frac{\pi}{6}$ et $\frac{7\pi}{6}$.
:::
:::

:::exercice Second degré
Résoudre dans $[0 ; 2\pi[$ :

1. $2\sin^2 x - 3\sin x + 1 = 0$
2. $2\cos^2 x + \sin x - 1 = 0$ (on remplacera $\cos^2 x$ par $1 - \sin^2 x$)

:::corrige
1. Avec $X = \sin x$ : $2X^2 - 3X + 1 = 0$, $X = 1$ ou $X = \frac{1}{2}$. Donc $x = \frac{\pi}{2}$, ou $x = \frac{\pi}{6}$, ou $x = \frac{5\pi}{6}$.
2. $2 - 2\sin^2 x + \sin x - 1 = 0 \iff 2\sin^2 x - \sin x - 1 = 0$ : $\sin x = 1$ ou $\sin x = -\frac{1}{2}$. Donc $x = \frac{\pi}{2}$, $x = \frac{7\pi}{6}$ ou $x = \frac{11\pi}{6}$.
:::
:::
