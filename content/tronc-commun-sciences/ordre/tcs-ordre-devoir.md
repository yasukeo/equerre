Durée : une heure.

:::exercice Exercice 1 (6 points) : comparer et démontrer
1. Comparer $4\sqrt{3}$ et $7$. (2 pts)
2. Montrer que pour tout $x \geq 0$, $x + 1 \geq 2\sqrt{x}$. (2 pts)
3. Montrer que $\dfrac{1}{\sqrt{3} - 1} = \dfrac{\sqrt{3} + 1}{2}$. (2 pts)

:::corrige
1. Deux positifs de carrés $48$ et $49$ : $4\sqrt{3} < 7$.
2. $x + 1 - 2\sqrt{x} = \left(\sqrt{x} - 1\right)^2 \geq 0$.
3. $\frac{1}{\sqrt{3} - 1} = \frac{\sqrt{3} + 1}{3 - 1} = \frac{\sqrt{3} + 1}{2}$.
:::
:::

:::exercice Exercice 2 (7 points) : encadrements
On sait que $3 \leq x \leq 4$ et $1 \leq y \leq 2$. Encadrer :

1. $x + y$ (1 pt)
2. $x - y$ (2 pts)
3. $xy$ (2 pts)
4. $\dfrac{x}{y}$ (2 pts)

:::corrige
1. $[4 ; 6]$.
2. $-y \in [-2 ; -1]$, donc $x - y \in [1 ; 3]$.
3. Tous positifs : $xy \in [3 ; 8]$.
4. $\frac{1}{y} \in \left[\frac{1}{2} ; 1\right]$, donc $\frac{x}{y} \in \left[\frac{3}{2} ; 4\right]$.
:::
:::

:::exercice Exercice 3 (7 points) : valeur absolue et intervalles
1. Résoudre $|x - 2| = 5$. (2 pts)
2. Résoudre $|3x - 1| < 2$ et écrire les solutions sous forme d’intervalle. (3 pts)
3. Déterminer $[-1 ; 3] \cap [2 ; 6]$ et $[-1 ; 3] \cup [2 ; 6]$. (2 pts)

:::corrige
1. $x = -3$ ou $x = 7$.
2. $-2 < 3x - 1 < 2 \iff -1 < 3x < 3 \iff -\frac{1}{3} < x < 1$ : $S = \left]-\frac{1}{3} ; 1\right[$.
3. $[2 ; 3]$ et $[-1 ; 6]$.
:::
:::
