Quatre exercices sur la deuxième partie du cours.

:::exercice Intervalles
1. Écrire sous forme d’intervalle : $-1 \leq x < 4$ ; $x > 2$ ; $x \leq -3$.
2. Déterminer $[-3 ; 2] \cap ]0 ; 5]$ et $[-3 ; 2] \cup ]0 ; 5]$.

:::corrige
1. $[-1 ; 4[$ ; $]2 ; +\infty[$ ; $]-\infty ; -3]$.
2. $]0 ; 2]$ et $[-3 ; 5]$.
:::
:::

:::exercice Valeurs absolues
1. Calculer $|3 - \pi|$, $\left|\sqrt{2} - 2\right|$ et $\left|1 - \sqrt{3}\right| + \left|2 - \sqrt{3}\right|$.
2. Simplifier $A = |x - 1| + |x + 2|$ pour $x \in [-2 ; 1]$.

:::corrige
1. $\pi - 3$ ; $2 - \sqrt{2}$ ; $\left(\sqrt{3} - 1\right) + \left(2 - \sqrt{3}\right) = 1$.
2. Pour $-2 \leq x \leq 1$ : $x - 1 \leq 0$ et $x + 2 \geq 0$, donc $A = 1 - x + x + 2 = 3$.
:::
:::

:::exercice Équations et inéquations
Résoudre dans $\mathbb{R}$ :

1. $|x - 3| = 2$
2. $|2x + 1| \leq 3$
3. $|x - 1| > 4$
4. $|x + 2| = -1$

:::corrige
1. $x = 1$ ou $x = 5$.
2. $-3 \leq 2x + 1 \leq 3 \iff -2 \leq x \leq 1$ : $S = [-2 ; 1]$.
3. La distance de $x$ à $1$ dépasse $4$ : $S = ]-\infty ; -3[ \cup ]5 ; +\infty[$.
4. Une valeur absolue n’est jamais négative : $S = \emptyset$.
:::
:::

:::exercice Valeurs approchées
On sait que $1{,}414 < \sqrt{2} < 1{,}415$.

1. Encadrer $3\sqrt{2} - 1$ et en donner une valeur approchée par défaut à $10^{-2}$ près.
2. Encadrer $\frac{1}{\sqrt{2}}$ et en donner une valeur approchée par défaut à $10^{-2}$ près.

:::corrige
1. $4{,}242 < 3\sqrt{2} < 4{,}245$, donc $3{,}242 < 3\sqrt{2} - 1 < 3{,}245$ : la valeur par défaut à $10^{-2}$ près est $3{,}24$.
2. $\frac{1}{1{,}415} < \frac{1}{\sqrt{2}} < \frac{1}{1{,}414}$, soit $0{,}7067 < \frac{1}{\sqrt{2}} < 0{,}7073$ : la valeur par défaut à $10^{-2}$ près est $0{,}70$.
:::
:::
