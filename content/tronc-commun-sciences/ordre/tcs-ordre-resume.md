## Inégalités

:::propriete
- $a \leq b \iff b - a \geq 0$.
- Multiplier par un négatif change le sens. Additionner deux inégalités de même sens : oui. Soustraire : non.
- Pour $a, b > 0$ : $a \leq b \iff a^2 \leq b^2 \iff \sqrt{a} \leq \sqrt{b}$, et $a \leq b \iff \frac{1}{a} \geq \frac{1}{b}$.
- $a^2 + b^2 \geq 2ab$ ; $a + \frac{1}{a} \geq 2$ pour $a > 0$.
:::

## Valeur absolue et encadrements

:::propriete
- $|x - a|$ : distance de $x$ à $a$. $|x - a| \leq r \iff x \in [a - r ; a + r]$.
- Encadrer $x - y$ : on encadre d’abord $-y$, puis on additionne.
:::

:::attention
Pour $a, b > 0$ : $a \leq b \iff a^2 \leq b^2$ ; pour des négatifs, le sens change.
:::
