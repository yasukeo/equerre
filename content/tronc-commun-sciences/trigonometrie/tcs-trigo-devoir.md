Durée : une heure.

:::exercice Exercice 1 (5 points) : radians
1. Convertir $150°$ en radians et $\frac{7\pi}{4}$ en degrés. (2 pts)
2. Donner l’abscisse curviligne principale du point associé à $\frac{31\pi}{6}$. (3 pts)

:::corrige
1. $\frac{5\pi}{6}$ et $315°$.
2. $\frac{31\pi}{6} = 6\pi - \frac{5\pi}{6}$ : l’abscisse principale est $-\frac{5\pi}{6}$.
:::
:::

:::exercice Exercice 2 (8 points) : valeurs
1. Calculer $\cos \frac{4\pi}{3}$, $\sin\left(-\frac{3\pi}{4}\right)$ et $\tan \frac{5\pi}{6}$. (4 pts)
2. On sait que $\cos x = \frac{1}{3}$ et $x \in \left[-\frac{\pi}{2} ; 0\right]$. Calculer $\sin x$ et $\tan x$. (4 pts)

:::corrige
1. $\cos\left(\pi + \frac{\pi}{3}\right) = -\frac{1}{2}$ ; $\sin\left(-\frac{3\pi}{4}\right) = -\sin \frac{3\pi}{4} = -\frac{\sqrt{2}}{2}$ ; $\tan \frac{5\pi}{6} = \frac{\frac{1}{2}}{-\frac{\sqrt{3}}{2}} = -\frac{\sqrt{3}}{3}$.
2. $\sin^2 x = 1 - \frac{1}{9} = \frac{8}{9}$, et $\sin x \leq 0$ sur cet intervalle : $\sin x = -\frac{2\sqrt{2}}{3}$, puis $\tan x = -2\sqrt{2}$.
:::
:::

:::exercice Exercice 3 (7 points) : simplifications
1. Simplifier $A = \sin(\pi - x) - \cos\left(\frac{\pi}{2} - x\right) + \cos(\pi + x) + \cos(-x)$. (3 pts)
2. Montrer que $(1 + \tan^2 x)\cos^2 x = 1$ là où $\tan x$ existe. (2 pts)
3. Montrer que $\sin^4 x - \cos^4 x = 2\sin^2 x - 1$. (2 pts)

:::corrige
1. $\sin x - \sin x - \cos x + \cos x = 0$.
2. $1 + \tan^2 x = \frac{1}{\cos^2 x}$, donc le produit vaut $1$.
3. $\sin^4 x - \cos^4 x = (\sin^2 x - \cos^2 x)(\sin^2 x + \cos^2 x) = \sin^2 x - (1 - \sin^2 x) = 2\sin^2 x - 1$.
:::
:::
