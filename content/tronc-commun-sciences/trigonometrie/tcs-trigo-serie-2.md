Quatre exercices sur la deuxième partie du cours.

:::exercice Valeurs exactes
Calculer :

1. $\cos \frac{2\pi}{3}$ et $\sin \frac{2\pi}{3}$
2. $\cos \frac{5\pi}{4}$ et $\sin \frac{5\pi}{4}$
3. $\cos\left(-\frac{\pi}{6}\right)$ et $\sin\left(-\frac{\pi}{6}\right)$
4. $\tan \frac{3\pi}{4}$

:::corrige
1. $\frac{2\pi}{3} = \pi - \frac{\pi}{3}$ : $-\frac{1}{2}$ et $\frac{\sqrt{3}}{2}$.
2. $\frac{5\pi}{4} = \pi + \frac{\pi}{4}$ : $-\frac{\sqrt{2}}{2}$ et $-\frac{\sqrt{2}}{2}$.
3. $\frac{\sqrt{3}}{2}$ et $-\frac{1}{2}$.
4. $\frac{\sin \frac{3\pi}{4}}{\cos \frac{3\pi}{4}} = \frac{\frac{\sqrt{2}}{2}}{-\frac{\sqrt{2}}{2}} = -1$.
:::
:::

:::exercice Du sinus au cosinus
1. On sait que $\cos x = -\frac{5}{13}$ et $x \in [\pi ; 2\pi]$. Calculer $\sin x$ et $\tan x$.
2. On sait que $\tan x = 2$ et $x \in \left]0 ; \frac{\pi}{2}\right[$. Calculer $\cos x$ et $\sin x$.

:::corrige
1. $\sin^2 x = 1 - \frac{25}{169} = \frac{144}{169}$, et $\sin x \leq 0$ sur $[\pi ; 2\pi]$ : $\sin x = -\frac{12}{13}$, puis $\tan x = \frac{12}{5}$.
2. $\frac{1}{\cos^2 x} = 1 + 4 = 5$, et $\cos x > 0$ : $\cos x = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}$, puis $\sin x = \tan x \cos x = \frac{2\sqrt{5}}{5}$.
:::
:::

:::exercice Simplifier
Simplifier :

1. $A = \sin(\pi - x) + \cos\left(\frac{\pi}{2} + x\right) + \sin(-x)$
2. $B = \cos(\pi + x) - \sin\left(\frac{\pi}{2} - x\right) + 2\cos(-x)$
3. $C = \cos \frac{\pi}{7} + \cos \frac{2\pi}{7} + \cos \frac{5\pi}{7} + \cos \frac{6\pi}{7}$

:::corrige
1. $\sin x - \sin x - \sin x = -\sin x$.
2. $-\cos x - \cos x + 2\cos x = 0$.
3. $\cos \frac{6\pi}{7} = \cos\left(\pi - \frac{\pi}{7}\right) = -\cos \frac{\pi}{7}$ et $\cos \frac{5\pi}{7} = -\cos \frac{2\pi}{7}$ : $C = 0$.
:::
:::

:::exercice Une identité
Montrer que pour tout réel $x$ :

1. $(\cos x + \sin x)^2 + (\cos x - \sin x)^2 = 2$
2. $\cos^4 x - \sin^4 x = \cos^2 x - \sin^2 x$

:::corrige
1. En développant : $2\cos^2 x + 2\sin^2 x = 2$.
2. $\cos^4 x - \sin^4 x = (\cos^2 x - \sin^2 x)(\cos^2 x + \sin^2 x) = \cos^2 x - \sin^2 x$.
:::
:::
