## Radian et cercle

:::propriete
- $\pi$ rad $= 180°$.
- Les abscisses curvilignes d’un point sont $x + 2k\pi$ ; l’abscisse principale est dans $]-\pi ; \pi]$.
:::

## Formules

:::propriete
- $M(\cos x ; \sin x)$ ; $\cos^2 x + \sin^2 x = 1$ ; $\tan x = \frac{\sin x}{\cos x}$ ; $1 + \tan^2 x = \frac{1}{\cos^2 x}$.
- $\frac{\pi}{6}$ : $\left(\frac{\sqrt{3}}{2} ; \frac{1}{2}\right)$ ; $\frac{\pi}{4}$ : $\left(\frac{\sqrt{2}}{2} ; \frac{\sqrt{2}}{2}\right)$ ; $\frac{\pi}{3}$ : $\left(\frac{1}{2} ; \frac{\sqrt{3}}{2}\right)$.
- $-x$ : $\cos$ garde, $\sin$ change de signe. $\pi - x$ : $\sin$ garde, $\cos$ change. $\pi + x$ : les deux changent. $\frac{\pi}{2} - x$ : $\cos$ et $\sin$ s’échangent.
:::

:::attention
Le signe de $\cos x$ et de $\sin x$ dépend du quart de cercle où se trouve le point.
:::
