## Repère

:::propriete
- $\overrightarrow{AB}(x_B - x_A ; y_B - y_A)$ ; milieu $\left(\frac{x_A + x_B}{2} ; \frac{y_A + y_B}{2}\right)$.
- Repère orthonormé : $AB = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2}$.
- $\det(\vec{u}, \vec{v}) = ab' - a'b$ ; nul si et seulement si les vecteurs sont colinéaires.
:::

## Droites

:::propriete
- Paramétrique : $x = x_A + at$, $y = y_A + bt$.
- Cartésienne : $\alpha x + \beta y + \gamma = 0$, vecteur directeur $(-\beta ; \alpha)$.
- Réduite : $y = mx + p$, pente $m = \frac{y_B - y_A}{x_B - x_A}$.
- Parallèles : même pente ; perpendiculaires (repère orthonormé) : $mm' = -1$.
:::

:::attention
Vérifiez toujours une équation trouvée en y remplaçant les coordonnées des points connus.
:::
