## Points

:::propriete
- Milieu : $\left(\frac{x_A + x_B}{2} ; \frac{y_A + y_B}{2}\right)$.
- Distance (repère orthonormé) : $AB = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2}$.
:::

## Vecteurs

:::propriete
- $\overrightarrow{AB}(x_B - x_A ; y_B - y_A)$.
- $ABCD$ parallélogramme $\iff \overrightarrow{AB} = \overrightarrow{DC}$.
- $\vec{u} + \vec{v}(a + a' ; b + b')$ ; $k\vec{u}(ka ; kb)$.
- Colinéaires $\iff ab' - a'b = 0$ ; $A$, $B$, $C$ alignés $\iff \overrightarrow{AB}$ et $\overrightarrow{AC}$ colinéaires.
:::

:::attention
Pour un triangle rectangle, on compare le plus grand carré des côtés à la somme des deux autres.
:::
