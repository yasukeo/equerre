Quatre exercices sur la deuxième partie du cours.

:::exercice Coordonnées de vecteurs
On donne $A(1 ; -2)$, $B(4 ; 2)$ et $C(-1 ; 3)$. Calculer les coordonnées de $\overrightarrow{AB}$, $\overrightarrow{BC}$ et $\overrightarrow{CA}$, puis vérifier que leur somme est nulle.

:::corrige
$\overrightarrow{AB}(3 ; 4)$, $\overrightarrow{BC}(-5 ; 1)$, $\overrightarrow{CA}(2 ; -5)$. Somme : $(3 - 5 + 2 ; 4 + 1 - 5) = (0 ; 0)$.
:::
:::

:::exercice Parallélogramme
Avec les points de l’exercice précédent, déterminer les coordonnées du point $D$ tel que $ABCD$ soit un parallélogramme.

:::corrige
$\overrightarrow{DC} = \overrightarrow{AB}$ : $(-1 - x ; 3 - y) = (3 ; 4)$, donc $D(-4 ; -1)$.
:::
:::

:::exercice Opérations
Soit $\vec{u}(2 ; -1)$ et $\vec{v}(-3 ; 4)$. Calculer les coordonnées de $\vec{u} + \vec{v}$, $3\vec{u}$ et $2\vec{u} - \vec{v}$.

:::corrige
$(-1 ; 3)$ ; $(6 ; -3)$ ; $(4 + 3 ; -2 - 4) = (7 ; -6)$.
:::
:::

:::exercice Colinéarité et alignement
1. Les vecteurs $\vec{u}(3 ; -2)$ et $\vec{v}(-6 ; 4)$ sont-ils colinéaires ? Et $\vec{w}(1 ; 2)$ et $\vec{z}(3 ; 5)$ ?
2. Les points $E(1 ; 2)$, $F(3 ; 6)$ et $G(5 ; 10)$ sont-ils alignés ?
3. Trouver $y$ pour que $H(2 ; y)$ soit aligné avec $E$ et $F$.

:::corrige
1. $\vec{v} = -2\vec{u}$ : oui. $1 \times 5 - 3 \times 2 = -1 \neq 0$ : non.
2. $\overrightarrow{EF}(2 ; 4)$ et $\overrightarrow{EG}(4 ; 8) = 2\overrightarrow{EF}$ : oui.
3. $\overrightarrow{EH}(1 ; y - 2)$ doit être proportionnel à $(2 ; 4)$ : $y - 2 = 2$, donc $y = 4$.
:::
:::
