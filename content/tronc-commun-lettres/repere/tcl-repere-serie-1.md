Quatre exercices sur la première partie du cours. Le repère est orthonormé.

:::exercice Milieux
1. Calculer les coordonnées du milieu de $[AB]$ avec $A(-3 ; 4)$ et $B(5 ; -2)$.
2. $I(2 ; 1)$ est le milieu de $[CD]$, avec $C(-1 ; 3)$. Calculer les coordonnées de $D$.

:::corrige
1. $(1 ; 1)$.
2. $\frac{-1 + x_D}{2} = 2$ et $\frac{3 + y_D}{2} = 1$ : $D(5 ; -1)$.
:::
:::

:::exercice Distances
Calculer les distances $AB$ et $CD$ avec $A(1 ; 2)$, $B(4 ; 6)$, $C(-2 ; 0)$ et $D(3 ; -1)$.

:::corrige
$AB = \sqrt{9 + 16} = 5$ ; $CD = \sqrt{25 + 1} = \sqrt{26}$.
:::
:::

:::exercice Nature d’un triangle
On donne $A(0 ; 1)$, $B(4 ; 3)$ et $C(2 ; 7)$.

1. Calculer $AB^2$, $BC^2$ et $AC^2$.
2. Quelle est la nature du triangle $ABC$ ?

:::corrige
1. $AB^2 = 16 + 4 = 20$ ; $BC^2 = 4 + 16 = 20$ ; $AC^2 = 4 + 36 = 40$.
2. $AB = BC$ et $AB^2 + BC^2 = AC^2$ : rectangle et isocèle en $B$.
:::
:::

:::exercice Un cercle
Soit $\mathcal{C}$ le cercle de centre $\Omega(1 ; 2)$ passant par $A(4 ; 6)$.

1. Calculer le rayon de $\mathcal{C}$.
2. Les points $B(-2 ; -2)$ et $C(6 ; 2)$ sont-ils sur $\mathcal{C}$ ?

:::corrige
1. $\Omega A = \sqrt{9 + 16} = 5$.
2. $\Omega B = \sqrt{9 + 16} = 5$ : oui. $\Omega C = \sqrt{25 + 0} = 5$ : oui.
:::
:::
