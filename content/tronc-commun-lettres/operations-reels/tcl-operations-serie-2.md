Quatre exercices sur la deuxième partie du cours.

:::exercice Racines carrées
Simplifier :

1. $\sqrt{72}$
2. $\sqrt{12} + \sqrt{27}$
3. $\left(\sqrt{5}\right)^2 + \sqrt{16}$
4. $\sqrt{2} \times \sqrt{8}$

:::corrige
1. $\sqrt{36 \times 2} = 6\sqrt{2}$.
2. $2\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}$.
3. $5 + 4 = 9$.
4. $\sqrt{16} = 4$.
:::
:::

:::exercice Développer
Développer et réduire :

1. $(x + 4)^2$
2. $(3x - 2)^2$
3. $(x - 7)(x + 7)$
4. $(2x + 1)(x - 3)$

:::corrige
1. $x^2 + 8x + 16$.
2. $9x^2 - 12x + 4$.
3. $x^2 - 49$.
4. $2x^2 - 5x - 3$.
:::
:::

:::exercice Factoriser
Factoriser :

1. $5x^2 + 10x$
2. $x^2 - 49$
3. $4x^2 - 12x + 9$
4. $(x - 2)(x + 5) + (x - 2)(3x - 1)$

:::corrige
1. $5x(x + 2)$.
2. $(x - 7)(x + 7)$.
3. $(2x - 3)^2$.
4. $(x - 2)\left[(x + 5) + (3x - 1)\right] = (x - 2)(4x + 4) = 4(x - 2)(x + 1)$.
:::
:::

:::exercice Identités et racines
Calculer :

1. $\left(1 + \sqrt{2}\right)^2$
2. $\left(\sqrt{3} - 1\right)\left(\sqrt{3} + 1\right)$
3. $\left(\sqrt{5} - 2\right)^2$

:::corrige
1. $1 + 2\sqrt{2} + 2 = 3 + 2\sqrt{2}$.
2. $3 - 1 = 2$.
3. $5 - 4\sqrt{5} + 4 = 9 - 4\sqrt{5}$.
:::
:::
