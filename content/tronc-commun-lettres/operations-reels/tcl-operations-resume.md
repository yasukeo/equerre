## Calcul numérique

:::propriete
- $\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$ ; $\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$ ; diviser, c’est multiplier par l’inverse.
- $a^m \times a^n = a^{m + n}$ ; $\frac{a^m}{a^n} = a^{m - n}$ ; $(a^m)^n = a^{mn}$ ; $a^{-n} = \frac{1}{a^n}$.
- Écriture scientifique : $a \times 10^n$ avec $1 \leq a < 10$.
- $\sqrt{ab} = \sqrt{a}\sqrt{b}$ ; $\left(\sqrt{a}\right)^2 = a$.
:::

## Calcul littéral

:::propriete
$(a + b)^2 = a^2 + 2ab + b^2$ ; $(a - b)^2 = a^2 - 2ab + b^2$ ; $(a - b)(a + b) = a^2 - b^2$.
:::

:::attention
$\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}$ et $(a + b)^2 \neq a^2 + b^2$.
:::
