## Racines carrées

:::definition
Pour $a \geq 0$, la **racine carrée** de $a$, notée $\sqrt{a}$, est le nombre positif dont le carré vaut $a$ : $\left(\sqrt{a}\right)^2 = a$.
:::

:::propriete
Pour $a \geq 0$ et $b > 0$ : $\sqrt{ab} = \sqrt{a} \times \sqrt{b}$ et $\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$.
:::

:::exemple
- $\sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$.
- $\sqrt{12} + \sqrt{27} = 2\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}$.
- $\sqrt{2} \times \sqrt{8} = \sqrt{16} = 4$.
:::

:::attention
$\sqrt{9 + 16} = \sqrt{25} = 5$, alors que $\sqrt{9} + \sqrt{16} = 7$ : la racine d’une somme n’est pas la somme des racines.
:::

## Identités remarquables

:::propriete
Pour tous réels $a$ et $b$ :

- $(a + b)^2 = a^2 + 2ab + b^2$ ;
- $(a - b)^2 = a^2 - 2ab + b^2$ ;
- $(a - b)(a + b) = a^2 - b^2$.
:::

## Développer

:::exemple
- $(x + 3)^2 = x^2 + 6x + 9$.
- $(2x - 1)^2 = 4x^2 - 4x + 1$.
- $(x - 5)(x + 5) = x^2 - 25$.
- $(2x + 1)(x - 3) = 2x^2 - 6x + x - 3 = 2x^2 - 5x - 3$.
:::

## Factoriser

:::propriete
Pour factoriser, on cherche un **facteur commun**, ou on reconnaît une **identité remarquable**.
:::

:::exemple
- $3x^2 - 6x = 3x(x - 2)$.
- $x^2 - 16 = (x - 4)(x + 4)$.
- $x^2 + 10x + 25 = (x + 5)^2$.
- $(x + 1)(2x - 3) - (x + 1)(x + 4) = (x + 1)\left[(2x - 3) - (x + 4)\right] = (x + 1)(x - 7)$.
:::

:::attention
Dans une différence de produits, attention aux parenthèses : $-(x + 4) = -x - 4$.
:::
