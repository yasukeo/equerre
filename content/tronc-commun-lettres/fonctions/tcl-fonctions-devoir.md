Durée : une heure.

:::exercice Exercice 1 (6 points) : images et antécédents
Soit $f(x) = 3x^2 - 2$.

1. Calculer $f(0)$, $f(-1)$ et $f(2)$. (3 pts)
2. Trouver les antécédents de $25$. (3 pts)

:::corrige
1. $-2$ ; $1$ ; $10$.
2. $3x^2 - 2 = 25 \iff x^2 = 9$ : $3$ et $-3$.
:::
:::

:::exercice Exercice 2 (8 points) : une fonction affine
On cherche la fonction affine $g$ telle que $g(1) = 5$ et $g(3) = 1$.

1. Déterminer $g(x)$. (4 pts)
2. Donner le sens de variation de $g$. (1 pt)
3. Résoudre $g(x) = 0$. (1 pt)
4. Résoudre $g(x) \geq 3$. (2 pts)

:::corrige
1. $a = \frac{1 - 5}{3 - 1} = -2$, et $-2 + b = 5$ donne $b = 7$ : $g(x) = -2x + 7$.
2. $a < 0$ : décroissante.
3. $-2x + 7 = 0 \iff x = 3{,}5$.
4. $-2x + 7 \geq 3 \iff -2x \geq -4 \iff x \leq 2$.
:::
:::

:::exercice Exercice 3 (6 points) : un tableau de variations
Une fonction $h$ est définie sur $[-2 ; 5]$. Elle décroît de $h(-2) = 4$ jusqu’à $h(1) = -3$, puis croît jusqu’à $h(5) = 2$.

1. Donner le maximum et le minimum de $h$. (2 pts)
2. Comparer $h(2)$ et $h(4)$. (2 pts)
3. Combien l’équation $h(x) = 0$ a-t-elle de solutions ? (2 pts)

:::corrige
1. Maximum $4$ (en $-2$) ; minimum $-3$ (en $1$).
2. $h$ croissante sur $[1 ; 5]$ : $h(2) < h(4)$.
3. Une sur $[-2 ; 1]$ (de $4$ à $-3$) et une sur $[1 ; 5]$ (de $-3$ à $2$) : deux solutions.
:::
:::
