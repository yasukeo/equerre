:::exercice Problème 1 : louer une voiture
Pour une journée de location, l’agence A demande $200$ dirhams plus $2$ dirhams par kilomètre ; l’agence B demande $3$ dirhams par kilomètre.

1. Exprimer les prix $A(x)$ et $B(x)$ pour $x$ kilomètres. Quelle fonction est linéaire ?
2. Calculer les deux prix pour $150$ km, puis pour $300$ km.
3. Pour quelle distance les deux agences coûtent-elles le même prix ?
4. Dans un repère, les deux droites se coupent en un point. Donner ses coordonnées et expliquer quelle agence choisir selon la distance.

:::corrige
1. $A(x) = 2x + 200$ (affine) et $B(x) = 3x$ (linéaire).
2. $150$ km : $A = 500$, $B = 450$. $300$ km : $A = 800$, $B = 900$.
3. $2x + 200 = 3x \iff x = 200$ km.
4. Le point $(200 ; 600)$. Avant $200$ km, la droite de B est au-dessous : B est moins chère ; après $200$ km, c’est A.
:::
:::

:::exercice Problème 2 : aire et périmètre d’un carré
Pour un carré de côté $x$ (en cm, $x > 0$), on note $A(x) = x^2$ son aire et $P(x) = 4x$ son périmètre.

1. Calculer $A$ et $P$ pour $x = 2$, $x = 4$ et $x = 6$.
2. Quelle fonction est linéaire ? Quelle fonction est une fonction carré ?
3. Pour quelle valeur de $x$ l’aire et le périmètre ont-ils la même mesure ?
4. Pour quelles valeurs de $x$ l’aire dépasse-t-elle le périmètre ?

:::corrige
1. $x = 2$ : $A = 4$, $P = 8$. $x = 4$ : $A = 16$, $P = 16$. $x = 6$ : $A = 36$, $P = 24$.
2. $P$ est linéaire ; $A$ est la fonction carré.
3. $x^2 = 4x \iff x(x - 4) = 0$, et $x > 0$ : $x = 4$.
4. $x^2 > 4x \iff x(x - 4) > 0$ ; comme $x > 0$, il faut $x > 4$.
:::
:::
