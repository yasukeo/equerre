## Vocabulaire

:::propriete
- Image de $a$ : $f(a)$, une seule. Antécédents de $b$ : solutions de $f(x) = b$, zéro, un ou plusieurs.
- Pas de dénominateur nul ; pas de nombre négatif sous une racine.
- Croissante : $x$ augmente, $f(x)$ augmente. Décroissante : $f(x)$ diminue.
:::

## Fonctions à connaître

:::propriete
- Linéaire $ax$ : proportionnalité, droite par l’origine.
- Affine $ax + b$ : droite, pente $a = \frac{f(x_2) - f(x_1)}{x_2 - x_1}$, $f(0) = b$ ; croissante si $a > 0$.
- Carré : parabole, minimum $0$. Inverse : hyperbole, décroissante sur chaque intervalle.
:::

:::attention
Pour trouver une fonction affine, on calcule d’abord $a$, puis $b$ avec un point connu.
:::
