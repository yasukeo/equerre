Durée : une heure.

:::exercice Exercice 1 (6 points) : comparer et encadrer
1. Comparer $\frac{7}{9}$ et $\frac{4}{5}$. (2 pts)
2. Comparer $2\sqrt{3}$ et $3{,}5$. (2 pts)
3. On sait que $-1 \leq x \leq 4$. Encadrer $2x - 3$. (2 pts)

:::corrige
1. $\frac{35}{45} < \frac{36}{45}$ : $\frac{7}{9} < \frac{4}{5}$.
2. Carrés $12$ et $12{,}25$ : $2\sqrt{3} < 3{,}5$.
3. $-2 \leq 2x \leq 8$, donc $-5 \leq 2x - 3 \leq 5$.
:::
:::

:::exercice Exercice 2 (7 points) : intervalles et valeur absolue
1. Écrire $-3 \leq x < 2$ sous forme d’intervalle. (1 pt)
2. Déterminer $]-\infty ; 4] \cap [1 ; 6]$ et $]-\infty ; 4] \cup [1 ; 6]$. (4 pts)
3. Calculer $|-5| + |2 - 9|$. (2 pts)

:::corrige
1. $[-3 ; 2[$.
2. $[1 ; 4]$ et $]-\infty ; 6]$.
3. $5 + 7 = 12$.
:::
:::

:::exercice Exercice 3 (7 points) : équation et inéquation
1. Résoudre $|x - 5| = 2$. (2 pts)
2. Résoudre $|x + 3| \leq 4$ et écrire les solutions sous forme d’intervalle. (3 pts)
3. Traduire l’inéquation précédente par une phrase avec le mot « distance ». (2 pts)

:::corrige
1. $x = 3$ ou $x = 7$.
2. $-4 \leq x + 3 \leq 4 \iff -7 \leq x \leq 1$ : $S = [-7 ; 1]$.
3. La distance entre $x$ et $-3$ est inférieure ou égale à $4$.
:::
:::
