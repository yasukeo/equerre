Quatre exercices sur la deuxième partie du cours.

:::exercice Intervalles
1. Écrire sous forme d’intervalle : $x \geq -1$ ; $-2 < x \leq 5$ ; $x < 0$.
2. Déterminer $[-3 ; 2] \cap [0 ; 5]$ et $[-3 ; 2] \cup [0 ; 5]$.
3. Déterminer $]-\infty ; 1] \cap [-2 ; +\infty[$.

:::corrige
1. $[-1 ; +\infty[$ ; $]-2 ; 5]$ ; $]-\infty ; 0[$.
2. $[0 ; 2]$ et $[-3 ; 5]$.
3. $[-2 ; 1]$.
:::
:::

:::exercice Valeurs absolues
1. Calculer $|-7|$, $|2 - 5|$ et $|\pi - 4|$.
2. Quelle est la distance entre $-2$ et $5$ ? Entre $-6$ et $-1$ ?

:::corrige
1. $7$ ; $3$ ; $4 - \pi$.
2. $|-2 - 5| = 7$ ; $|-6 - (-1)| = 5$.
:::
:::

:::exercice Équations
Résoudre :

1. $|x - 4| = 3$
2. $|x + 1| = 5$
3. $|x| = -2$

:::corrige
1. $x = 1$ ou $x = 7$.
2. $|x - (-1)| = 5$ : $x = -6$ ou $x = 4$.
3. Pas de solution.
:::
:::

:::exercice Inéquations
Résoudre et écrire les solutions sous forme d’intervalle :

1. $|x - 2| \leq 3$
2. $|x| < 4$
3. $|x - 1| \geq 2$

:::corrige
1. $[-1 ; 5]$.
2. $]-4 ; 4[$.
3. La distance de $x$ à $1$ est au moins $2$ : $]-\infty ; -1] \cup [3 ; +\infty[$.
:::
:::
