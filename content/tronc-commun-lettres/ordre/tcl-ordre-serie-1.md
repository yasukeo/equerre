Quatre exercices sur la première partie du cours.

:::exercice Comparer
Comparer :

1. $\frac{5}{8}$ et $\frac{3}{5}$
2. $-\frac{4}{3}$ et $-\frac{5}{4}$
3. $\sqrt{10}$ et $3$
4. $2\sqrt{3}$ et $3{,}5$

:::corrige
1. $\frac{25}{40} > \frac{24}{40}$ : $\frac{5}{8} > \frac{3}{5}$.
2. $-\frac{16}{12} < -\frac{15}{12}$ : $-\frac{4}{3} < -\frac{5}{4}$.
3. Carrés $10$ et $9$ : $\sqrt{10} > 3$.
4. Carrés $12$ et $12{,}25$ : $2\sqrt{3} < 3{,}5$.
:::
:::

:::exercice Encadrer
On sait que $2 \leq x \leq 5$. Encadrer :

1. $x + 3$
2. $2x$
3. $-x$
4. $3 - x$

:::corrige
1. $5 \leq x + 3 \leq 8$.
2. $4 \leq 2x \leq 10$.
3. $-5 \leq -x \leq -2$.
4. $-2 \leq 3 - x \leq 1$.
:::
:::

:::exercice Valeurs approchées
On sait que $2{,}23 < \sqrt{5} < 2{,}24$.

1. Encadrer $3\sqrt{5}$ et $1 + \sqrt{5}$.
2. Sachant que $\sqrt{5} = 2{,}236\ldots$, donner l’arrondi de $\sqrt{5}$ à $10^{-2}$ près.

:::corrige
1. $6{,}69 < 3\sqrt{5} < 6{,}72$ et $3{,}23 < 1 + \sqrt{5} < 3{,}24$.
2. $2{,}24$, car $2{,}236$ est plus proche de $2{,}24$ que de $2{,}23$.
:::
:::

:::exercice Un rectangle mesuré
La longueur $L$ d’un rectangle vérifie $5{,}2 \leq L \leq 5{,}3$ et sa largeur $\ell$ vérifie $3{,}1 \leq \ell \leq 3{,}2$ (en mètres).

1. Encadrer le périmètre $P = 2(L + \ell)$.
2. Encadrer l’aire $A = L \times \ell$.

:::corrige
1. $8{,}3 \leq L + \ell \leq 8{,}5$, donc $16{,}6 \leq P \leq 17$.
2. Tous les nombres sont positifs : $5{,}2 \times 3{,}1 \leq A \leq 5{,}3 \times 3{,}2$, soit $16{,}12 \leq A \leq 16{,}96$.
:::
:::
