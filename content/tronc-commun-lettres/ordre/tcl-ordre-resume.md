## Inégalités

:::propriete
- $a > b \iff a - b > 0$.
- Ajouter, soustraire, multiplier par un positif : même sens. Multiplier par un négatif : le sens change.
- Pour deux positifs, comparer leurs carrés suffit.
:::

## Intervalles et valeur absolue

:::propriete
- $[a ; b]$ bornes comprises ; $]a ; b[$ bornes exclues ; $\cap$ : dans les deux ; $\cup$ : dans l’un au moins.
- $|a - b|$ : distance entre $a$ et $b$.
- $|x - a| \leq r \iff x \in [a - r ; a + r]$ ; $|x - a| = r \iff x = a \pm r$.
:::

:::attention
Pour encadrer $3 - x$, on encadre d’abord $-x$ en changeant le sens, puis on ajoute $3$.
:::
