Trois exercices sur la première partie du cours.

:::exercice Types de caractères
Pour chaque caractère, dire s’il est qualitatif, quantitatif discret ou quantitatif continu.

1. La filière choisie par un élève.
2. Le nombre de frères et sœurs.
3. Le temps de trajet jusqu’au lycée.
4. La pointure de chaussures.

:::corrige
1. Qualitatif.
2. Quantitatif discret.
3. Quantitatif continu.
4. Quantitatif discret (les pointures sont des valeurs isolées).
:::
:::

:::exercice Fréquences et cumuls
On a demandé à $40$ familles leur nombre d’enfants : $0$ enfant : $4$ familles ; $1$ : $10$ ; $2$ : $14$ ; $3$ : $8$ ; $4$ : $4$.

1. Calculer la fréquence de chaque valeur, en pourcentage.
2. Calculer les effectifs cumulés croissants.
3. Combien de familles ont au plus $2$ enfants ? Au moins $3$ enfants ?
4. Calculer les angles du diagramme circulaire.

:::corrige
1. $10\,\%$ ; $25\,\%$ ; $35\,\%$ ; $20\,\%$ ; $10\,\%$.
2. $4$ ; $14$ ; $28$ ; $36$ ; $40$.
3. $28$ familles ; $40 - 28 = 12$ familles.
4. $36°$ ; $90°$ ; $126°$ ; $72°$ ; $36°$ (le total fait $360°$).
:::
:::

:::exercice Histogramme
Les salaires mensuels, en milliers de dirhams, de $50$ employés sont répartis en classes : $[3 ; 5[$ : $10$ employés ; $[5 ; 7[$ : $20$ ; $[7 ; 11[$ : $16$ ; $[11 ; 15[$ : $4$.

1. Pourquoi ne peut-on pas tracer des rectangles de hauteur égale à l’effectif ?
2. On prend comme unité d’aire un employé pour un rectangle de largeur $1$ et de hauteur $1$. Quelle hauteur faut-il donner à chaque rectangle ?

:::corrige
1. Les classes n’ont pas la même amplitude ($2$, $2$, $4$, $4$) : c’est l’aire qui doit être proportionnelle à l’effectif.
2. Hauteur $=$ effectif $\div$ amplitude : $5$ ; $10$ ; $4$ ; $1$.
:::
:::
