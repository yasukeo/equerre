Durée : une heure.

:::exercice Exercice 1 (6 points) : un caractère qualitatif
On a demandé à $50$ élèves leur sport préféré : football : $20$ ; basket : $12$ ; handball : $8$ ; athlétisme : $10$.

1. Quel est le type du caractère étudié ? (1 pt)
2. Calculer la fréquence de chaque sport en pourcentage. (2 pts)
3. Calculer les angles du diagramme circulaire. (3 pts)

:::corrige
1. Qualitatif.
2. $40\,\%$ ; $24\,\%$ ; $16\,\%$ ; $20\,\%$.
3. $144°$ ; $86{,}4°$ ; $57{,}6°$ ; $72°$.
:::
:::

:::exercice Exercice 2 (8 points) : une série discrète
Notes de $20$ élèves : $6$ (×$2$), $8$ (×$3$), $10$ (×$6$), $12$ (×$5$), $14$ (×$3$), $18$ (×$1$).

1. Donner le mode et l’étendue. (1 pt)
2. Calculer la moyenne. (2 pts)
3. Déterminer la médiane. (2 pts)
4. Calculer la variance et l’écart-type. (3 pts)

:::corrige
1. Mode $10$ ; étendue $18 - 6 = 12$.
2. $\frac{12 + 24 + 60 + 60 + 42 + 18}{20} = \frac{216}{20} = 10{,}8$.
3. Effectifs cumulés : $2$, $5$, $11$, $16$, $19$, $20$. Les rangs $10$ et $11$ valent $10$ : $Me = 10$.
4. $\frac{72 + 192 + 600 + 720 + 588 + 324}{20} = \frac{2\,496}{20} = 124{,}8$ ; $V = 124{,}8 - 10{,}8^2 = 124{,}8 - 116{,}64 = 8{,}16$ et $\sigma \approx 2{,}86$.
:::
:::

:::exercice Exercice 3 (6 points) : une série en classes
Âges de $40$ personnes : $[20 ; 30[$ : $6$ ; $[30 ; 40[$ : $14$ ; $[40 ; 50[$ : $12$ ; $[50 ; 60[$ : $8$.

1. Donner la classe modale. (1 pt)
2. Calculer l’âge moyen. (3 pts)
3. Déterminer la médiane à l’aide des effectifs cumulés. (2 pts)

:::corrige
1. $[30 ; 40[$.
2. $\frac{6 \times 25 + 14 \times 35 + 12 \times 45 + 8 \times 55}{40} = \frac{150 + 490 + 540 + 440}{40} = \frac{1\,620}{40} = 40{,}5$ ans.
3. Effectifs cumulés : $6$, $20$, $32$, $40$. Exactement $20$ personnes, la moitié, ont moins de $40$ ans : $Me = 40$ ans.
:::
:::
