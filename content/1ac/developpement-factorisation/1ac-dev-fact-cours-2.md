## Factoriser

:::propriete
La distributivité se lit aussi de droite à gauche :

$$ka + kb = k(a + b) \qquad ka - kb = k(a - b)$$

Transformer une somme en produit, c’est **factoriser**. Le nombre $k$ présent dans chaque terme est le **facteur commun**.
:::

:::exemple
- $6x + 6y = 6(x + y)$.
- $5a - 15 = 5 \times a - 5 \times 3 = 5(a - 3)$.
- $x^2 + 4x = x \times x + 4 \times x = x(x + 4)$.
- $13 \times 47 + 13 \times 53 = 13 \times (47 + 53) = 13 \times 100 = 1\,300$.
:::

:::attention
Pour vérifier une factorisation, on développe le résultat : on doit retrouver l’expression de départ.
:::

## Réduire une expression

:::definition
Des termes **semblables** ont la même partie littérale : $3x$ et $-5x$ sont semblables, $3x$ et $3x^2$ ne le sont pas. **Réduire** une expression, c’est regrouper les termes semblables.
:::

:::exemple
- $4x + 7x = (4 + 7)x = 11x$ : c’est une factorisation par $x$.
- $5a - 2 + 3a + 8 = 8a + 6$.
- $2x^2 + 3x - x^2 + x = x^2 + 4x$.
:::

## Développer puis réduire

:::exemple
$A = 3(x + 2) - 2(x - 5)$

$= 3x + 6 - 2x + 10$

$= x + 16$.
:::

:::attention
Le $-$ devant $2(x - 5)$ porte sur tout le produit : $-2 \times (-5) = +10$.
:::
