Durée : une heure.

:::exercice Exercice 1 (3 points) : valeur d’une expression
Calculer $G = 2x^2 - 5x + 1$ pour $x = 3$ et pour $x = -2$.

:::corrige
- $x = 3$ : $18 - 15 + 1 = 4$.
- $x = -2$ : $2 \times 4 + 10 + 1 = 19$.
:::
:::

:::exercice Exercice 2 (5 points) : développer
Développer (1 pt chacun) :

1. $8(x + 2)$
2. $5(3a - 4)$
3. $-6(y + 1)$
4. $-(4 - 3b)$
5. $2x(x + 5)$

:::corrige
1. $8x + 16$.
2. $15a - 20$.
3. $-6y - 6$.
4. $-4 + 3b$.
5. $2x^2 + 10x$.
:::
:::

:::exercice Exercice 3 (5 points) : factoriser
Factoriser (1 pt chacun) :

1. $9x + 9$
2. $12a - 8$
3. $x^2 + 7x$
4. $3y - 3z$
5. $25 \times 7 + 25 \times 3$ (puis calculer)

:::corrige
1. $9(x + 1)$.
2. $4(3a - 2)$.
3. $x(x + 7)$.
4. $3(y - z)$.
5. $25 \times 10 = 250$.
:::
:::

:::exercice Exercice 4 (4 points) : développer et réduire
$H = 4(x - 3) - 3(x - 5)$.

1. Développer et réduire $H$. (3 pts)
2. Calculer $H$ pour $x = 10$. (1 pt)

:::corrige
1. $H = 4x - 12 - 3x + 15 = x + 3$.
2. $10 + 3 = 13$.
:::
:::

:::exercice Exercice 5 (3 points) : problème
Un triangle a des côtés de longueurs $x$, $x + 2$ et $2x - 1$ (en cm).

1. Exprimer son périmètre et le réduire. (2 pts)
2. Calculer le périmètre pour $x = 4$. (1 pt)

:::corrige
1. $x + (x + 2) + (2x - 1) = 4x + 1$.
2. $4 \times 4 + 1 = 17$ cm.
:::
:::
