Trois exercices sur la première partie du cours.

:::exercice Valeur d’une expression
Calculer $E = 3x + 2$ et $F = x^2 - x$ pour $x = 4$, puis pour $x = -1$.

:::corrige
- $x = 4$ : $E = 12 + 2 = 14$ ; $F = 16 - 4 = 12$.
- $x = -1$ : $E = -3 + 2 = -1$ ; $F = 1 - (-1) = 2$.
:::
:::

:::exercice Développer
Développer :

1. $6(x + 5)$
2. $3(2y - 7)$
3. $-4(a + 3)$
4. $-5(2 - b)$
5. $x(x - 9)$

:::corrige
1. $6x + 30$.
2. $6y - 21$.
3. $-4a - 12$.
4. $-10 + 5b$.
5. $x^2 - 9x$.
:::
:::

:::exercice Parenthèses et calcul mental
1. Supprimer les parenthèses : $8 + (x - 3)$ ; $8 - (x - 3)$ ; $-(2a + 5)$.
2. Calculer mentalement avec la distributivité : $9 \times 104$ ; $6 \times 98$.

:::corrige
1. $5 + x$ ; $11 - x$ ; $-2a - 5$.
2. $9 \times 100 + 9 \times 4 = 936$ ; $6 \times 100 - 6 \times 2 = 588$.
:::
:::
