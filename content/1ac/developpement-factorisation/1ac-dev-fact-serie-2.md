Trois exercices sur la deuxième partie du cours.

:::exercice Factoriser
Factoriser :

1. $4x + 4y$
2. $7a - 21$
3. $10b + 15$
4. $x^2 - 3x$
5. $17 \times 36 + 17 \times 64$ (puis calculer)

:::corrige
1. $4(x + y)$.
2. $7(a - 3)$.
3. $5(2b + 3)$.
4. $x(x - 3)$.
5. $17 \times (36 + 64) = 17 \times 100 = 1\,700$.
:::
:::

:::exercice Réduire
Réduire :

1. $9x - 4x + x$
2. $3a + 5 - 7a + 2$
3. $x^2 + 2x + 3x^2 - 5x$

:::corrige
1. $6x$.
2. $-4a + 7$.
3. $4x^2 - 3x$.
:::
:::

:::exercice Développer puis réduire
1. $A = 2(x + 4) + 3(x - 1)$
2. $B = 5(a - 2) - (a + 6)$
3. $C = -3(y - 2) - 2(4 - y)$

:::corrige
1. $2x + 8 + 3x - 3 = 5x + 5$.
2. $5a - 10 - a - 6 = 4a - 16$.
3. $-3y + 6 - 8 + 2y = -y - 2$.
:::
:::
