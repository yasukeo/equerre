Trois exercices sur la première partie du cours.

:::exercice Comparer et ranger
1. Comparer $5{,}8$ et $5{,}79$, puis $0{,}305$ et $0{,}35$.
2. Ranger dans l’ordre croissant : $2{,}5$ ; $2{,}05$ ; $2{,}55$ ; $2{,}505$.

:::corrige
1. $5{,}8 > 5{,}79$ ; $0{,}305 < 0{,}35$.
2. $2{,}05 < 2{,}5 < 2{,}505 < 2{,}55$.
:::
:::

:::exercice Additions et soustractions
Calculer : $12{,}5 + 3{,}75$ ; $8{,}06 + 11{,}9$ ; $20 - 7{,}36$ ; $15{,}4 - 9{,}87$.

:::corrige
$16{,}25$ ; $19{,}96$ ; $12{,}64$ ; $5{,}53$.
:::
:::

:::exercice Multiplications
Calculer : $2{,}3 \times 1{,}4$ ; $0{,}6 \times 0{,}5$ ; $4{,}56 \times 100$ ; $0{,}07 \times 1\,000$ ; $12 \times 2{,}5$.

:::corrige
$3{,}22$ ; $0{,}3$ ; $456$ ; $70$ ; $30$.
:::
:::
