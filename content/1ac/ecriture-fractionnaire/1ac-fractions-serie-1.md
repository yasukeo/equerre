Trois exercices sur la première partie du cours.

:::exercice Quotients
Donner l’écriture décimale de : $\frac{15}{3}$ ; $\frac{7}{4}$ ; $\frac{3}{8}$ ; $\frac{9}{10}$.

:::corrige
$5$ ; $1{,}75$ ; $0{,}375$ ; $0{,}9$.
:::
:::

:::exercice Compléter
Compléter : $\frac{3}{4} = \frac{\ldots}{20}$ ; $\frac{5}{6} = \frac{25}{\ldots}$ ; $\frac{14}{21} = \frac{2}{\ldots}$.

:::corrige
$\frac{15}{20}$ ; $\frac{25}{30}$ ; $\frac{2}{3}$.
:::
:::

:::exercice Simplifier
Rendre irréductible : $\frac{18}{24}$ ; $\frac{35}{45}$ ; $\frac{48}{60}$ ; $\frac{56}{70}$.

:::corrige
$\frac{3}{4}$ ; $\frac{7}{9}$ ; $\frac{4}{5}$ ; $\frac{4}{5}$.
:::
:::
