Trois exercices sur la première partie du cours.

:::exercice Écrire et calculer
1. Écrire sous forme d’une puissance : $7 \times 7 \times 7 \times 7$ ; $0{,}5 \times 0{,}5 \times 0{,}5$.
2. Calculer : $3^4$ ; $10^3$ ; $1{,}2^2$ ; $9^1$ ; $9^0$.

:::corrige
1. $7^4$ ; $0{,}5^3$.
2. $81$ ; $1\,000$ ; $1{,}44$ ; $9$ ; $1$.
:::
:::

:::exercice Signe
Sans calculer, donner le signe, puis calculer :

1. $(-2)^4$
2. $(-2)^5$
3. $(-1)^{2025}$
4. $(-0{,}1)^2$

:::corrige
1. Exposant pair : positif ; $(-2)^4 = 16$.
2. Exposant impair : négatif ; $(-2)^5 = -32$.
3. Exposant impair : $(-1)^{2025} = -1$.
4. Exposant pair : $(-0{,}1)^2 = 0{,}01$.
:::
:::

:::exercice Attention aux parenthèses
Calculer $(-5)^2$, $-5^2$, $(-5)^3$ et $-5^3$.

:::corrige
- $(-5)^2 = 25$.
- $-5^2 = -25$.
- $(-5)^3 = -125$.
- $-5^3 = -125$.

Pour un exposant impair, les deux écritures donnent le même résultat.
:::
:::
