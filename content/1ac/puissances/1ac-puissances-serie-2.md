Trois exercices sur la deuxième partie du cours.

:::exercice Puissances de 10
1. Écrire sous forme d’une puissance de 10 : $100\,000$ ; $10$ ; $1$.
2. Calculer : $4{,}8 \times 10^2$ ; $0{,}07 \times 10^4$ ; $25 \times 10^3$.

:::corrige
1. $10^5$ ; $10^1$ ; $10^0$.
2. $480$ ; $700$ ; $25\,000$.
:::
:::

:::exercice Priorités
Calculer :

1. $C = 2 \times 3^2$
2. $D = (2 \times 3)^2$
3. $E = 5^2 - 4^2$
4. $F = (5 - 4)^2$

:::corrige
1. $C = 2 \times 9 = 18$.
2. $D = 6^2 = 36$.
3. $E = 25 - 16 = 9$.
4. $F = 1^2 = 1$.
:::
:::

:::exercice Avec des relatifs
Calculer $G = -2^2 + (-3)^2 - 2 \times (-1)^3$.

:::corrige
$-2^2 = -4$ ; $(-3)^2 = 9$ ; $(-1)^3 = -1$, donc $2 \times (-1)^3 = -2$.

$G = -4 + 9 - (-2) = -4 + 9 + 2 = 7$.
:::
:::
