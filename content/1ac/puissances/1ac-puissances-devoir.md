Durée : une heure.

:::exercice Exercice 1 (5 points) : calculer
1. Écrire $4 \times 4 \times 4$ sous forme d’une puissance. (1 pt)
2. Calculer : $2^6$ ; $0{,}2^3$ ; $11^2$ ; $7^0$. (4 pts)

:::corrige
1. $4^3$.
2. $64$ ; $0{,}008$ ; $121$ ; $1$.
:::
:::

:::exercice Exercice 2 (5 points) : signe
Calculer (1 pt chacun) : $(-4)^2$ ; $-4^2$ ; $(-4)^3$ ; $(-1)^{100}$ ; $(-1)^{101}$.

:::corrige
$16$ ; $-16$ ; $-64$ ; $1$ ; $-1$.
:::
:::

:::exercice Exercice 3 (4 points) : puissances de 10
Calculer (1 pt chacun) : $10^4$ ; $3{,}2 \times 10^3$ ; $0{,}005 \times 10^2$ ; $7 \times 10^5$.

:::corrige
$10\,000$ ; $3\,200$ ; $0{,}5$ ; $700\,000$.
:::
:::

:::exercice Exercice 4 (6 points) : priorités et problème
1. Calculer $H = 1 + 3 \times 2^3$ et $K = (1 + 3) \times 2^3$. (3 pts)
2. Une boîte cubique a une arête de $5$ cm. On range $8$ de ces boîtes dans un carton. Calculer le volume total des boîtes. (3 pts)

:::corrige
1. $H = 1 + 3 \times 8 = 25$ ; $K = 4 \times 8 = 32$.
2. Une boîte : $5^3 = 125$ cm³. Huit boîtes : $8 \times 125 = 1\,000$ cm³.
:::
:::
