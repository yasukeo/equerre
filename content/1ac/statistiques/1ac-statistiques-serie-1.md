Trois exercices sur la première partie du cours.

:::exercice Vocabulaire
Pour chaque enquête, donner la population, le caractère, et dire s’il est quantitatif ou qualitatif.

1. La couleur des voitures garées devant le collège.
2. La pointure des joueurs d’une équipe de football.

:::corrige
1. Population : les voitures garées devant le collège ; caractère : la couleur ; qualitatif.
2. Population : les joueurs de l’équipe ; caractère : la pointure ; quantitatif.
:::
:::

:::exercice Dépouiller
Voici les notes sur $10$ obtenues par $20$ élèves à un contrôle :

$6$ ; $8$ ; $5$ ; $7$ ; $8$ ; $9$ ; $6$ ; $7$ ; $7$ ; $10$ ; $5$ ; $8$ ; $7$ ; $6$ ; $9$ ; $7$ ; $8$ ; $4$ ; $7$ ; $6$.

1. Donner l’effectif de chaque note.
2. Vérifier l’effectif total.
3. Combien d’élèves ont au moins $8$ ?

:::corrige
1. $4$ : $1$ ; $5$ : $2$ ; $6$ : $4$ ; $7$ : $6$ ; $8$ : $4$ ; $9$ : $2$ ; $10$ : $1$.
2. $1 + 2 + 4 + 6 + 4 + 2 + 1 = 20$.
3. $4 + 2 + 1 = 7$ élèves.
:::
:::

:::exercice Fréquences
Avec les données de l’exercice précédent :

1. Calculer la fréquence de la note $7$, en fraction, en décimal et en pourcentage.
2. Calculer la fréquence, en pourcentage, des élèves qui ont au moins $8$.

:::corrige
1. $\frac{6}{20} = 0{,}3 = 30\,\%$.
2. $\frac{7}{20} = 0{,}35 = 35\,\%$.
:::
:::
