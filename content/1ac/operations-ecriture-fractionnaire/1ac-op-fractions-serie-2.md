Trois exercices sur la deuxième partie du cours.

:::exercice Par un entier
Calculer : $3 \times \frac{2}{7}$ ; $4 \times \frac{5}{12}$ ; $6 \times \frac{3}{4}$.

:::corrige
$\frac{6}{7}$ ; $\frac{5}{3}$ ; $\frac{18}{4} = \frac{9}{2}$.
:::
:::

:::exercice Deux fractions
Calculer et simplifier : $\frac{2}{3} \times \frac{4}{5}$ ; $\frac{3}{4} \times \frac{2}{9}$ ; $\frac{5}{6} \times \frac{9}{10}$ ; $\frac{7}{8} \times \frac{4}{21}$.

:::corrige
$\frac{8}{15}$ ; $\frac{1}{6}$ ; $\frac{3}{4}$ ; $\frac{28}{168} = \frac{1}{6}$.
:::
:::

:::exercice Fraction d’une fraction
1. Quelle fraction d’une tarte représentent les $\frac{2}{3}$ de sa moitié ?
2. Un champ est cultivé aux $\frac{3}{5}$ ; le blé occupe les $\frac{2}{3}$ de la partie cultivée. Quelle fraction du champ occupe le blé ?

:::corrige
1. $\frac{2}{3} \times \frac{1}{2} = \frac{1}{3}$.
2. $\frac{2}{3} \times \frac{3}{5} = \frac{6}{15} = \frac{2}{5}$.
:::
:::
