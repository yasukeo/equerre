Trois exercices sur la première partie du cours. Donner les résultats sous forme irréductible.

:::exercice Même dénominateur
Calculer : $\frac{3}{7} + \frac{2}{7}$ ; $\frac{9}{10} - \frac{3}{10}$ ; $\frac{5}{12} + \frac{1}{12}$.

:::corrige
$\frac{5}{7}$ ; $\frac{3}{5}$ ; $\frac{6}{12} = \frac{1}{2}$.
:::
:::

:::exercice Dénominateurs différents
Calculer : $\frac{1}{4} + \frac{3}{8}$ ; $\frac{2}{3} + \frac{1}{4}$ ; $\frac{5}{6} - \frac{3}{4}$ ; $\frac{7}{10} - \frac{2}{5}$.

:::corrige
$\frac{5}{8}$ ; $\frac{11}{12}$ ; $\frac{1}{12}$ ; $\frac{7}{10} - \frac{4}{10} = \frac{3}{10}$.
:::
:::

:::exercice Avec des entiers
Calculer : $2 + \frac{3}{5}$ ; $1 - \frac{3}{8}$ ; $3 - \frac{5}{4}$.

:::corrige
$\frac{13}{5}$ ; $\frac{5}{8}$ ; $\frac{12}{4} - \frac{5}{4} = \frac{7}{4}$.
:::
:::
