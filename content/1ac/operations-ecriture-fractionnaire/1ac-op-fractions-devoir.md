Durée : une heure. Donner les résultats sous forme irréductible.

:::exercice Exercice 1 (7 points) : additionner et soustraire
Calculer : $\frac{4}{9} + \frac{2}{9}$ (2 pts) ; $\frac{3}{5} + \frac{1}{10}$ (2 pts) ; $\frac{5}{6} - \frac{2}{9}$ (3 pts).

:::corrige
$\frac{6}{9} = \frac{2}{3}$ ; $\frac{7}{10}$ ; $\frac{15}{18} - \frac{4}{18} = \frac{11}{18}$.
:::
:::

:::exercice Exercice 2 (7 points) : multiplier
Calculer : $5 \times \frac{3}{10}$ (2 pts) ; $\frac{4}{7} \times \frac{14}{9}$ (2 pts) ; $\frac{3}{8} \times \frac{4}{15}$ (3 pts).

:::corrige
$\frac{15}{10} = \frac{3}{2}$ ; $\frac{56}{63} = \frac{8}{9}$ ; $\frac{12}{120} = \frac{1}{10}$.
:::
:::

:::exercice Exercice 3 (6 points) : une bouteille
Une bouteille contient $\frac{3}{4}$ de litre de jus. On en boit les $\frac{2}{3}$.

1. Quelle quantité de jus a-t-on bue ? (3 pts)
2. Quelle quantité reste-t-il ? (3 pts)

:::corrige
1. $\frac{2}{3} \times \frac{3}{4} = \frac{1}{2}$ litre.
2. $\frac{3}{4} - \frac{1}{2} = \frac{1}{4}$ litre.
:::
:::
