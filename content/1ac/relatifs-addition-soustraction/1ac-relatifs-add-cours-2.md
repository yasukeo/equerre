## Soustraire, c’est ajouter l’opposé

:::propriete
Pour soustraire un nombre relatif, on **ajoute son opposé** : $a - b = a + (\text{opposé de } b)$.
:::

:::exemple
- $(+3) - (+8) = (+3) + (-8) = -5$.
- $(-4) - (-10) = (-4) + (+10) = +6$.
- $(-2) - (+5) = (-2) + (-5) = -7$.
:::

## Écriture simplifiée

:::propriete
Une fois toutes les soustractions changées en additions, on peut supprimer les signes $+$ d’addition et les parenthèses : chaque nombre garde son propre signe.
:::

:::exemple
$(+7) + (-3) - (-4) - (+6)$

$= (+7) + (-3) + (+4) + (-6)$

$= 7 - 3 + 4 - 6$.

Positifs : $7 + 4 = 11$. Négatifs : $-3 - 6 = -9$. Donc le résultat est $11 - 9 = 2$.
:::

:::attention
Dans l’écriture simplifiée $7 - 3 + 4 - 6$, chaque signe se lit avec le nombre qui le suit : on additionne les nombres $7$, $-3$, $4$ et $-6$.
:::

## Distance entre deux points

:::propriete
Sur une droite graduée, la distance entre deux points $A$ et $B$ est la différence entre la plus grande abscisse et la plus petite.
:::

:::exemple
Avec $A(-3)$ et $B(5)$ : $AB = 5 - (-3) = 5 + 3 = 8$.

Avec $C(-7)$ et $D(-2)$ : $CD = -2 - (-7) = -2 + 7 = 5$.
:::
