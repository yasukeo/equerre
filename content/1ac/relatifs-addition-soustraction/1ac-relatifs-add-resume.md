## Addition

:::propriete
- **Même signe** : on garde le signe, on additionne les distances à zéro : $(-3) + (-5) = -8$.
- **Signes contraires** : signe du plus éloigné de zéro, on soustrait les distances : $(-8) + (+3) = -5$.
- Deux opposés ont une somme nulle.
:::

## Soustraction

:::propriete
- $a - b = a + (\text{opposé de } b)$ : $(+2) - (-6) = (+2) + (+6) = 8$.
- Écriture simplifiée : $(+5) - (+9) + (-1) = 5 - 9 - 1 = -5$.
- Distance $AB$ = plus grande abscisse $-$ plus petite.
:::

:::attention
On regroupe les positifs et les négatifs pour calculer une longue somme sans erreur.
:::
