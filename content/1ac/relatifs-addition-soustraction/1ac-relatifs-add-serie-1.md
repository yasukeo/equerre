Trois exercices sur la première partie du cours.

:::exercice Même signe
Calculer :

1. $(+6) + (+9)$
2. $(-6) + (-9)$
3. $(-1{,}5) + (-2{,}5)$
4. $(-12) + (-8)$

:::corrige
1. $+15$.
2. $-15$.
3. $-4$.
4. $-20$.
:::
:::

:::exercice Signes contraires
Calculer :

1. $(+10) + (-4)$
2. $(-10) + (+4)$
3. $(-7) + (+7)$
4. $(+2{,}5) + (-6)$

:::corrige
1. $+6$ : le signe de $10$, et $10 - 4 = 6$.
2. $-6$.
3. $0$ : ce sont deux opposés.
4. $-3{,}5$ : le signe de $-6$, et $6 - 2{,}5 = 3{,}5$.
:::
:::

:::exercice Regrouper
Calculer en regroupant les positifs et les négatifs :

$B = (-3) + (+11) + (-9) + (+4) + (-2)$.

:::corrige
Positifs : $11 + 4 = 15$. Négatifs : $(-3) + (-9) + (-2) = -14$.

$B = (+15) + (-14) = +1$.
:::
:::
