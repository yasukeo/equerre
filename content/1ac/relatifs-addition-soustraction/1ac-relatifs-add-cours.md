## Deux nombres de même signe

:::propriete
Pour additionner deux nombres de **même signe**, on garde ce signe et on **additionne** les distances à zéro.
:::

:::exemple
- $(+4) + (+7) = +11$.
- $(-4) + (-7) = -11$ : une dette de $4$ dirhams et une dette de $7$ dirhams font une dette de $11$ dirhams.
- $(-2{,}5) + (-1{,}3) = -3{,}8$.
:::

## Deux nombres de signes contraires

:::propriete
Pour additionner deux nombres de **signes contraires**, on prend le signe de celui qui a la **plus grande** distance à zéro, et on **soustrait** la plus petite distance à zéro de la plus grande.
:::

:::exemple
- $(+9) + (-5)$ : les distances sont $9$ et $5$ ; $9$ est la plus grande, donc le signe est $+$, et $9 - 5 = 4$. Résultat : $+4$.
- $(-9) + (+5)$ : le signe est $-$ et $9 - 5 = 4$. Résultat : $-4$.
- $(-3{,}2) + (+1{,}2) = -2$.
:::

:::propriete
La somme de deux nombres **opposés** est nulle : $(-6) + (+6) = 0$.
:::

## Sommes de plusieurs nombres

:::propriete
Dans une somme, on peut changer l’ordre des termes et les regrouper comme on veut. On regroupe souvent les positifs entre eux et les négatifs entre eux.
:::

:::exemple
$A = (+5) + (-8) + (+3) + (-4)$.

Positifs : $(+5) + (+3) = +8$. Négatifs : $(-8) + (-4) = -12$.

Donc $A = (+8) + (-12) = -4$.
:::

:::attention
Ne pas confondre le signe d’un nombre et l’opération : dans $(+9) + (-5)$, le $+$ du milieu est l’addition, le $-$ est le signe de $-5$.
:::
