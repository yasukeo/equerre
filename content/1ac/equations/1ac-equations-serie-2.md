Trois exercices sur la deuxième partie du cours.

:::exercice Deux étapes
Résoudre :

1. $2x + 3 = 11$
2. $5x - 4 = 21$
3. $-3x + 10 = 4$
4. $4x + 9 = 1$

:::corrige
1. $2x = 8$, $x = 4$.
2. $5x = 25$, $x = 5$.
3. $-3x = -6$, $x = 2$.
4. $4x = -8$, $x = -2$.
:::
:::

:::exercice Réduire d’abord
Résoudre :

1. $3x + 4x = 28$
2. $6x - x + 2 = 17$

:::corrige
1. $7x = 28$, $x = 4$.
2. $5x + 2 = 17$, $5x = 15$, $x = 3$.
:::
:::

:::exercice Mettre en équation
1. Le double d’un nombre, augmenté de $7$, vaut $31$. Quel est ce nombre ?
2. Un stylo coûte $x$ dirhams et un cahier coûte $4$ dirhams de plus. Pour $3$ stylos et $1$ cahier, on paie $24$ dirhams. Trouver le prix d’un stylo.

:::corrige
1. $2x + 7 = 31$, $2x = 24$, $x = 12$.
2. $3x + (x + 4) = 24$, donc $4x + 4 = 24$, $4x = 20$, $x = 5$. Un stylo coûte $5$ dirhams (et un cahier $9$ dirhams).
:::
:::
