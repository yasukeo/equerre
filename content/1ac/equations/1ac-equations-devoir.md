Durée : une heure.

:::exercice Exercice 1 (3 points) : tester
Le nombre $-2$ est-il solution de $4x + 11 = 3$ ? Et de $x - 5 = -3$ ? Justifier.

:::corrige
- $4 \times (-2) + 11 = 3$ : oui.
- $-2 - 5 = -7$, pas $-3$ : non.
:::
:::

:::exercice Exercice 2 (5 points) : équations de base
Résoudre (1 pt chacun) :

1. $x + 13 = 20$
2. $x - 7 = -2$
3. $9x = 54$
4. $\frac{x}{5} = -3$
5. $-x = 8$

:::corrige
1. $x = 7$.
2. $x = 5$.
3. $x = 6$.
4. $x = -15$.
5. $x = -8$.
:::
:::

:::exercice Exercice 3 (6 points) : deux étapes
Résoudre (2 pts chacun) :

1. $3x - 7 = 14$
2. $-4x + 2 = 18$
3. $2x + 5x - 3 = 25$

:::corrige
1. $3x = 21$, $x = 7$.
2. $-4x = 16$, $x = -4$.
3. $7x - 3 = 25$, $7x = 28$, $x = 4$.
:::
:::

:::exercice Exercice 4 (6 points) : problèmes
1. Trois nombres entiers consécutifs ont pour somme $72$. On appelle $x$ le plus petit. Écrire une équation et trouver les trois nombres. (3 pts)
2. Un taxi demande $5$ dirhams de prise en charge, puis $4$ dirhams par kilomètre. Une course a coûté $61$ dirhams. Combien de kilomètres a-t-elle duré ? (3 pts)

:::corrige
1. $x + (x + 1) + (x + 2) = 72$, donc $3x + 3 = 72$, $3x = 69$, $x = 23$. Les nombres sont $23$, $24$ et $25$.
2. $5 + 4x = 61$, $4x = 56$, $x = 14$ km.
:::
:::
