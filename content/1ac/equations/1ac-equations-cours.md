## Vocabulaire

:::definition
Une **équation** est une égalité qui contient une lettre inconnue, souvent notée $x$. Un nombre est une **solution** de l’équation si, en remplaçant $x$ par ce nombre, l’égalité est vraie. **Résoudre** l’équation, c’est trouver sa solution.
:::

:::exemple
$x + 7 = 12$ est une équation. Le nombre $5$ en est la solution, car $5 + 7 = 12$. Le nombre $4$ n’est pas solution, car $4 + 7 = 11$ et non $12$.
:::

## Tester un nombre

:::exemple
Le nombre $3$ est-il solution de $2x + 1 = 7$ ?

On remplace $x$ par $3$ : $2 \times 3 + 1 = 7$. L’égalité est vraie : $3$ est solution.
:::

## Les équations de base

:::propriete
- $x + a = b$ a pour solution $x = b - a$ : on **soustrait** $a$ des deux membres.
- $x - a = b$ a pour solution $x = b + a$ : on **ajoute** $a$ aux deux membres.
- $ax = b$ (avec $a$ non nul) a pour solution $x = \frac{b}{a}$ : on **divise** les deux membres par $a$.
- $\frac{x}{a} = b$ (avec $a$ non nul) a pour solution $x = a \times b$ : on **multiplie** les deux membres par $a$.
:::

:::exemple
- $x + 9 = 4$ : $x = 4 - 9 = -5$.
- $x - 2{,}5 = 6$ : $x = 6 + 2{,}5 = 8{,}5$.
- $4x = 30$ : $x = \frac{30}{4} = 7{,}5$.
- $\frac{x}{3} = -2$ : $x = 3 \times (-2) = -6$.
:::

:::attention
On termine toujours par une **vérification** : on remplace $x$ par la valeur trouvée dans l’équation de départ.
:::
