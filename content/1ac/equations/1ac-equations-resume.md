## Résoudre

:::propriete
- $x + a = b \Rightarrow x = b - a$ ; $x - a = b \Rightarrow x = b + a$.
- $ax = b \Rightarrow x = \frac{b}{a}$ ; $\frac{x}{a} = b \Rightarrow x = ab$ ($a$ non nul).
- $ax + b = c$ : d’abord $ax = c - b$, puis $x = \frac{c - b}{a}$.
:::

## Problèmes

:::propriete
Choisir l’inconnue, écrire l’équation, la résoudre, vérifier et répondre par une phrase.
:::

:::attention
Toujours vérifier en remplaçant $x$ dans l’équation de départ.
:::
