Trois exercices sur la première partie du cours.

:::exercice Tester
1. Le nombre $4$ est-il solution de $3x - 2 = 10$ ?
2. Le nombre $-1$ est-il solution de $5 - x = 4$ ?
3. Parmi $2$, $3$ et $6$, lequel est solution de $x \times x = 2x + 3$ ?

:::corrige
1. $3 \times 4 - 2 = 10$ : oui.
2. $5 - (-1) = 6$, pas $4$ : non.
3. Pour $2$ : $4$ et $7$, non. Pour $3$ : $9$ et $9$, oui. Pour $6$ : $36$ et $15$, non. La solution est $3$.
:::
:::

:::exercice Addition et soustraction
Résoudre :

1. $x + 8 = 15$
2. $x + 6 = 2$
3. $x - 4 = 9$
4. $x - 1{,}5 = -3$

:::corrige
1. $x = 7$.
2. $x = -4$.
3. $x = 13$.
4. $x = -1{,}5$.
:::
:::

:::exercice Multiplication et division
Résoudre :

1. $6x = 42$
2. $-5x = 35$
3. $\frac{x}{4} = 7$
4. $8x = 6$

:::corrige
1. $x = 7$.
2. $x = -7$.
3. $x = 28$.
4. $x = \frac{6}{8} = 0{,}75$.
:::
:::
