Quatre exercices sur la première partie du cours.

:::exercice Polynômes
Calculer :

1. $\lim_{x \to +\infty} (x^3 - 4x^2 + 2)$
2. $\lim_{x \to -\infty} (x^3 - 4x^2 + 2)$
3. $\lim_{x \to -\infty} (-2x^2 + x + 7)$
4. $\lim_{x \to +\infty} (5 - x^4)$

:::corrige
1. Comme $x^3$ : $+\infty$.
2. Comme $x^3$ : $-\infty$.
3. Comme $-2x^2$ : $-\infty$.
4. Comme $-x^4$ : $-\infty$.
:::
:::

:::exercice Fractions rationnelles
Calculer :

1. $\lim_{x \to +\infty} \dfrac{4x - 1}{2x + 3}$
2. $\lim_{x \to -\infty} \dfrac{x^2 + 1}{3x^2 - x}$
3. $\lim_{x \to +\infty} \dfrac{2x + 5}{x^2 + 1}$
4. $\lim_{x \to -\infty} \dfrac{x^2 - 2}{x + 1}$

:::corrige
1. $\frac{4x}{2x} = 2$.
2. $\frac{x^2}{3x^2} = \frac{1}{3}$.
3. $\frac{2x}{x^2} = \frac{2}{x} \to 0$.
4. $\frac{x^2}{x} = x \to -\infty$.
:::
:::

:::exercice Règles de calcul
Calculer :

1. $\lim_{x \to +\infty} \left(x + \dfrac{1}{x}\right)$
2. $\lim_{x \to +\infty} \left(3 - \dfrac{2}{x^2}\right)$
3. $\lim_{x \to +\infty} \left(\sqrt{x} + x\right)$
4. $\lim_{x \to -\infty} \dfrac{5}{x + 2}$

:::corrige
1. $+\infty + 0 = +\infty$.
2. $3 - 0 = 3$.
3. $+\infty + (+\infty) = +\infty$.
4. Le dénominateur tend vers $-\infty$ : la limite vaut $0$.
:::
:::

:::exercice Asymptotes horizontales
Montrer que chaque courbe admet une asymptote horizontale, et donner son équation.

1. $f(x) = \dfrac{6x + 1}{2x - 1}$
2. $g(x) = \dfrac{x - 4}{x^2 + 2}$

:::corrige
1. En $\pm\infty$, $f(x)$ a la limite de $\frac{6x}{2x} = 3$ : asymptote $y = 3$.
2. En $\pm\infty$, $g(x)$ a la limite de $\frac{x}{x^2} = \frac{1}{x}$, soit $0$ : asymptote $y = 0$, l’axe des abscisses.
:::
:::
