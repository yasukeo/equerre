Durée : une heure.

:::exercice Exercice 1 (6 points) : définition et parité
1. Déterminer l’ensemble de définition de $f(x) = \dfrac{x + 2}{x - 4}$ et de $g(x) = \sqrt{x + 3}$. (2 pts)
2. Étudier la parité de $h(x) = x^3 - 4x$ et de $k(x) = 3x^2 + 1$. (4 pts)

:::corrige
1. $D_f = \mathbb{R} \setminus \{4\}$ ; $D_g = [-3 ; +\infty[$.
2. $h(-x) = -x^3 + 4x = -h(x)$ : $h$ est impaire. $k(-x) = 3x^2 + 1 = k(x)$ : $k$ est paire.
:::
:::

:::exercice Exercice 2 (6 points) : un trinôme
Soit $f(x) = x^2 + 2x - 3$.

1. Déterminer le sommet de la parabole et les variations de $f$. (3 pts)
2. Donner le minimum de $f$. (1 pt)
3. Trouver les antécédents de $0$. (2 pts)

:::corrige
1. $\alpha = -1$ et $f(-1) = 1 - 2 - 3 = -4$ : sommet $S(-1 ; -4)$. $f$ décroît sur $]-\infty ; -1]$ et croît sur $[-1 ; +\infty[$.
2. Le minimum est $-4$.
3. $x^2 + 2x - 3 = (x + 3)(x - 1) = 0$ : les antécédents sont $-3$ et $1$.
:::
:::

:::exercice Exercice 3 (8 points) : deux courbes
Soit $f(x) = x^2$ et $g(x) = 2x + 3$.

1. Montrer que $f(x) - g(x) = (x - 3)(x + 1)$. (2 pts)
2. Calculer les coordonnées des points d’intersection de $C_f$ et $C_g$. (2 pts)
3. Étudier la position de $C_f$ par rapport à $C_g$. (2 pts)
4. Résoudre $f(x) \leq g(x)$. (2 pts)

:::corrige
1. $f(x) - g(x) = x^2 - 2x - 3 = (x - 3)(x + 1)$.
2. Pour $x = -1$ : $(-1 ; 1)$ ; pour $x = 3$ : $(3 ; 9)$.
3. Le produit est négatif sur $]-1 ; 3[$ : $C_f$ y est au-dessous de $C_g$ ; il est positif ailleurs : $C_f$ est au-dessus.
4. $S = [-1 ; 3]$.
:::
:::
