## Comparer des nombres

:::propriete
- Un nombre négatif est plus petit qu’un nombre positif.
- Entre deux négatifs, le plus petit est celui qui a la plus grande distance à zéro : $-7 < -4$.
- Pour comparer des fractions, on les écrit avec le même dénominateur positif.
:::

:::exemple
$-3{,}5 < -2{,}1$ ; $\frac{2}{3} \approx 0{,}667 > 0{,}6$ ; $-\frac{2}{3} < -0{,}6$.
:::

## Comparer avec la différence

:::propriete
Pour comparer $a$ et $b$, on calcule $a - b$ : si $a - b > 0$, alors $a > b$ ; si $a - b < 0$, alors $a < b$.
:::

:::exemple
$\frac{5}{8} - \frac{3}{5} = \frac{25}{40} - \frac{24}{40} = \frac{1}{40} > 0$, donc $\frac{5}{8} > \frac{3}{5}$.
:::

## Ordre et addition

:::propriete
On peut ajouter ou soustraire un même nombre aux deux membres d’une inégalité sans changer son sens : si $a < b$, alors $a + c < b + c$ et $a - c < b - c$.
:::

:::exemple
Si $a < b$, alors $a + 5 < b + 5$ et $a - 2 < b - 2$.
:::

:::propriete
Ajouter un nombre positif fait augmenter, ajouter un nombre négatif fait diminuer : si $c < 0$, alors $a + c < a$.
:::

:::attention
$-7 < -4$, même si $7 > 4$ : sur la droite graduée, $-7$ est plus à gauche.
:::
