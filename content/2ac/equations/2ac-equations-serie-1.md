Trois exercices sur la première partie du cours.

:::exercice Tester
Les nombres $-2$ et $4$ sont-ils solutions de $3x - 2 = x + 6$ ?

:::corrige
$-2$ : $-8$ et $4$, non. $4$ : $10$ et $10$, oui.
:::
:::

:::exercice Équations simples
Résoudre : $x + 9 = 4$ ; $x - 6 = -2$ ; $7x = 42$ ; $-3x = 15$ ; $\frac{x}{5} = -2$.

:::corrige
$x = -5$ ; $x = 4$ ; $x = 6$ ; $x = -5$ ; $x = -10$.
:::
:::

:::exercice Du type $ax + b = cx + d$
Résoudre :

1. $3x - 5 = x + 9$
2. $5x + 2 = 2x - 7$
3. $4 - x = 2x + 10$
4. $7x - 3 = 7x + 1$

:::corrige
1. $2x = 14$, $x = 7$.
2. $3x = -9$, $x = -3$.
3. $-3x = 6$, $x = -2$.
4. $-3 = 1$ est impossible : pas de solution.
:::
:::
