## Même dénominateur

:::propriete
$$
\frac{a}{b} + \frac{c}{b} = \frac{a + c}{b} \qquad \frac{a}{b} - \frac{c}{b} = \frac{a - c}{b}
$$

On additionne (ou on soustrait) les numérateurs, et on garde le dénominateur.
:::

:::exemple
$\frac{2}{7} + \frac{3}{7} = \frac{5}{7}$ et $\frac{5}{9} - \frac{8}{9} = \frac{-3}{9} = -\frac{1}{3}$.
:::

## Dénominateurs différents

:::propriete
On écrit d’abord les deux nombres avec un **dénominateur commun**, le plus petit possible (le plus petit multiple commun des dénominateurs), puis on applique la règle précédente.
:::

:::exemple
- $\frac{1}{4} + \frac{2}{3} = \frac{3}{12} + \frac{8}{12} = \frac{11}{12}$.
- $\frac{5}{6} - \frac{3}{4} = \frac{10}{12} - \frac{9}{12} = \frac{1}{12}$.
- $-\frac{2}{5} + \frac{1}{2} = -\frac{4}{10} + \frac{5}{10} = \frac{1}{10}$.
:::

:::attention
On n’additionne jamais les dénominateurs : $\frac{1}{2} + \frac{1}{3} = \frac{5}{6}$, et non $\frac{2}{5}$.
:::

## Avec un entier

:::propriete
Un entier $n$ s’écrit $\frac{n \times b}{b}$ : on peut ainsi l’ajouter à un rationnel de dénominateur $b$.
:::

:::exemple
$3 + \frac{2}{5} = \frac{15}{5} + \frac{2}{5} = \frac{17}{5}$ et $1 - \frac{7}{8} = \frac{8}{8} - \frac{7}{8} = \frac{1}{8}$.
:::
