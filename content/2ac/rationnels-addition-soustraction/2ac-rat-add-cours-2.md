## Sommes algébriques

:::propriete
On réduit tous les termes au même dénominateur, puis on calcule les numérateurs comme une somme algébrique de nombres relatifs.
:::

:::exemple
$\frac{1}{2} + \frac{1}{3} - \frac{1}{4} = \frac{6}{12} + \frac{4}{12} - \frac{3}{12} = \frac{7}{12}$.
:::

## Parenthèses

:::exemple
$A = \frac{1}{2} - \left(\frac{3}{4} - \frac{5}{6}\right)$. D’abord la parenthèse : $\frac{9}{12} - \frac{10}{12} = -\frac{1}{12}$. Puis $A = \frac{6}{12} + \frac{1}{12} = \frac{7}{12}$.
:::

## Trouver un terme inconnu

:::propriete
- Si $x + a = b$, alors $x = b - a$.
- Si $x - a = b$, alors $x = b + a$.
:::

:::exemple
$x + \frac{2}{5} = \frac{3}{4}$ donne $x = \frac{3}{4} - \frac{2}{5} = \frac{15}{20} - \frac{8}{20} = \frac{7}{20}$.
:::

## Fractions d’une quantité

:::exemple
Un réservoir est rempli aux $\frac{3}{4}$. On utilise une quantité égale au $\frac{1}{3}$ de sa capacité. Il reste $\frac{3}{4} - \frac{1}{3} = \frac{9}{12} - \frac{4}{12} = \frac{5}{12}$ de la capacité. Si le réservoir contient $120$ litres quand il est plein, il en reste $\frac{5}{12} \times 120 = 50$ litres.
:::

:::attention
Dans un problème, « le reste » se calcule souvent par $1 - (\ldots)$ : l’entier $1$ représente la quantité totale.
:::
