Trois exercices sur la première partie du cours. Donner les résultats sous forme irréductible.

:::exercice Même dénominateur
Calculer : $\frac{4}{11} + \frac{5}{11}$ ; $\frac{7}{8} - \frac{3}{8}$ ; $-\frac{5}{6} + \frac{1}{6}$ ; $\frac{2}{9} - \frac{7}{9}$.

:::corrige
$\frac{9}{11}$ ; $\frac{4}{8} = \frac{1}{2}$ ; $-\frac{4}{6} = -\frac{2}{3}$ ; $-\frac{5}{9}$.
:::
:::

:::exercice Dénominateurs différents
Calculer : $\frac{1}{3} + \frac{1}{6}$ ; $\frac{3}{4} - \frac{2}{5}$ ; $-\frac{1}{2} + \frac{5}{8}$ ; $\frac{7}{10} - \frac{4}{15}$.

:::corrige
- $\frac{2}{6} + \frac{1}{6} = \frac{1}{2}$.
- $\frac{15}{20} - \frac{8}{20} = \frac{7}{20}$.
- $-\frac{4}{8} + \frac{5}{8} = \frac{1}{8}$.
- $\frac{21}{30} - \frac{8}{30} = \frac{13}{30}$.
:::
:::

:::exercice Avec des entiers
Calculer : $2 + \frac{3}{4}$ ; $5 - \frac{2}{3}$ ; $-1 + \frac{5}{6}$.

:::corrige
$\frac{11}{4}$ ; $\frac{13}{3}$ ; $-\frac{1}{6}$.
:::
:::
