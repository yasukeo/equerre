Durée : une heure. Donner les résultats sous forme irréductible.

:::exercice Exercice 1 (6 points) : calculer
Calculer (2 pts chacune) : $\frac{3}{10} + \frac{4}{10}$ ; $\frac{5}{12} - \frac{11}{12}$ ; $\frac{2}{3} + \frac{1}{5}$.

:::corrige
$\frac{7}{10}$ ; $-\frac{6}{12} = -\frac{1}{2}$ ; $\frac{10}{15} + \frac{3}{15} = \frac{13}{15}$.
:::
:::

:::exercice Exercice 2 (8 points) : sommes algébriques
1. Calculer $E = \frac{3}{4} - \frac{1}{6} + \frac{1}{3}$. (3 pts)
2. Calculer $F = 1 - \left(\frac{2}{5} + \frac{1}{2}\right)$. (3 pts)
3. Trouver $x$ tel que $x + \frac{1}{4} = \frac{2}{3}$. (2 pts)

:::corrige
1. $\frac{9 - 2 + 4}{12} = \frac{11}{12}$.
2. $1 - \frac{9}{10} = \frac{1}{10}$.
3. $x = \frac{8}{12} - \frac{3}{12} = \frac{5}{12}$.
:::
:::

:::exercice Exercice 3 (6 points) : une bouteille d’eau
On boit le matin $\frac{1}{4}$ d’une bouteille, puis l’après-midi les $\frac{2}{5}$ de la bouteille.

1. Quelle fraction de la bouteille a-t-on bue ? Quelle fraction reste-t-il ? (4 pts)
2. La bouteille contient $1{,}5$ litre. Combien reste-t-il d’eau ? (2 pts)

:::corrige
1. $\frac{5}{20} + \frac{8}{20} = \frac{13}{20}$ ; il reste $\frac{7}{20}$.
2. $\frac{7}{20} \times 1{,}5 = 0{,}525$ litre.
:::
:::
