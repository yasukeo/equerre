## Règles

:::propriete
- $a^0 = 1$ ; $a^{-n} = \frac{1}{a^n}$.
- $a^m \times a^n = a^{m + n}$ ; $\frac{a^m}{a^n} = a^{m - n}$ ; $(a^m)^n = a^{mn}$ ; $(ab)^n = a^nb^n$.
- $(-a)^n$ : positif si $n$ pair, négatif si $n$ impair.
:::

## Écriture scientifique

:::propriete
- $a \times 10^n$ avec $1 \leq a < 10$.
- Pour calculer : nombres ensemble, puissances de $10$ ensemble.
:::

:::attention
$(-3)^2 = 9$ mais $-3^2 = -9$ ; et $a^m + a^n \neq a^{m + n}$.
:::
