Quatre exercices sur la deuxième partie du cours.

:::exercice Inverses
Donner l’inverse de : $\frac{3}{8}$ ; $-5$ ; $-\frac{4}{9}$ ; $\frac{1}{6}$.

:::corrige
$\frac{8}{3}$ ; $-\frac{1}{5}$ ; $-\frac{9}{4}$ ; $6$.
:::
:::

:::exercice Quotients
Calculer : $\frac{3}{5} \div \frac{9}{10}$ ; $-\frac{4}{7} \div 2$ ; $6 \div \frac{3}{4}$ ; $-\frac{5}{12} \div \left(-\frac{10}{3}\right)$.

:::corrige
$\frac{2}{3}$ ; $-\frac{2}{7}$ ; $8$ ; $\frac{5}{12} \times \frac{3}{10} = \frac{15}{120} = \frac{1}{8}$.
:::
:::

:::exercice Fractions étagées
Calculer : $\dfrac{\frac{2}{3}}{\frac{4}{9}}$ et $\dfrac{1 + \frac{1}{2}}{1 - \frac{1}{4}}$.

:::corrige
$\frac{2}{3} \times \frac{9}{4} = \frac{3}{2}$ ; $\frac{3/2}{3/4} = 2$.
:::
:::

:::exercice Des verres
Une bouteille contient $\frac{3}{4}$ de litre. Combien de verres de $\frac{1}{8}$ de litre peut-on remplir ? Et de verres de $\frac{3}{20}$ de litre ?

:::corrige
$\frac{3}{4} \div \frac{1}{8} = 6$ verres ; $\frac{3}{4} \div \frac{3}{20} = \frac{3}{4} \times \frac{20}{3} = 5$ verres.
:::
:::
