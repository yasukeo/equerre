Durée : une heure. Donner les résultats sous forme irréductible.

:::exercice Exercice 1 (6 points) : multiplier
Calculer (2 pts chacune) : $\frac{4}{9} \times \frac{3}{8}$ ; $-\frac{6}{5} \times \frac{10}{9}$ ; les $\frac{2}{3}$ de $45$.

:::corrige
$\frac{12}{72} = \frac{1}{6}$ ; $-\frac{60}{45} = -\frac{4}{3}$ ; $30$.
:::
:::

:::exercice Exercice 2 (8 points) : diviser
1. Donner l’inverse de $-\frac{7}{3}$. (1 pt)
2. Calculer $\frac{5}{6} \div \frac{10}{9}$. (2 pts)
3. Calculer $-\frac{3}{4} \div \left(-\frac{9}{8}\right)$. (2 pts)
4. Calculer $\dfrac{\frac{3}{5}}{\frac{6}{25}}$. (3 pts)

:::corrige
1. $-\frac{3}{7}$.
2. $\frac{5}{6} \times \frac{9}{10} = \frac{3}{4}$.
3. $\frac{3}{4} \times \frac{8}{9} = \frac{2}{3}$.
4. $\frac{3}{5} \times \frac{25}{6} = \frac{5}{2}$.
:::
:::

:::exercice Exercice 3 (6 points) : du miel
1. On répartit $\frac{5}{2}$ kg de miel dans des pots de $\frac{1}{4}$ kg. Combien de pots remplit-on ? (3 pts)
2. Le miel coûte $120$ dirhams le kilogramme. Combien coûtent $\frac{3}{4}$ kg ? (3 pts)

:::corrige
1. $\frac{5}{2} \div \frac{1}{4} = \frac{5}{2} \times 4 = 10$ pots.
2. $\frac{3}{4} \times 120 = 90$ dirhams.
:::
:::
