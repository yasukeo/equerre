Trois exercices sur la première partie du cours. Donner les résultats sous forme irréductible.

:::exercice Produits
Calculer : $\frac{3}{4} \times \frac{8}{9}$ ; $-\frac{2}{5} \times \frac{15}{4}$ ; $-\frac{7}{3} \times \left(-\frac{6}{14}\right)$ ; $5 \times \frac{3}{10}$.

:::corrige
$\frac{2}{3}$ ; $-\frac{3}{2}$ ; $1$ ; $\frac{3}{2}$.
:::
:::

:::exercice Fraction d’une quantité
Calculer :

1. les $\frac{2}{5}$ de $350$ dirhams ;
2. les $\frac{3}{8}$ de $64$ élèves ;
3. les $\frac{5}{6}$ de $1{,}2$ heure, en minutes.

:::corrige
1. $140$ dirhams.
2. $24$ élèves.
3. $1{,}2$ h $= 72$ min, et $\frac{5}{6} \times 72 = 60$ minutes.
:::
:::

:::exercice Plusieurs facteurs
Donner le signe, puis calculer : $\frac{2}{3} \times \left(-\frac{9}{4}\right) \times \left(-\frac{1}{6}\right)$ et $-\frac{1}{2} \times \frac{4}{5} \times \left(-\frac{5}{8}\right) \times \left(-2\right)$.

:::corrige
- Deux facteurs négatifs : positif, $\frac{18}{72} = \frac{1}{4}$.
- Trois facteurs négatifs : négatif ; $\frac{1 \times 4 \times 5 \times 2}{2 \times 5 \times 8} = \frac{40}{80} = \frac{1}{2}$, donc $-\frac{1}{2}$.
:::
:::
