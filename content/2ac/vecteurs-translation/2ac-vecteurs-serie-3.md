:::exercice Problème 1 : un parallélogramme
$ABCD$ est un parallélogramme. On note $E$ l’image de $C$ par la translation de vecteur $\overrightarrow{AB}$.

1. Écrire l’égalité de vecteurs qui définit $E$.
2. Montrer que $\overrightarrow{DC} = \overrightarrow{CE}$.
3. En déduire que $C$ est le milieu de $[DE]$.
4. Montrer que $ABEC$ est un parallélogramme.

:::corrige
1. $\overrightarrow{CE} = \overrightarrow{AB}$.
2. $ABCD$ est un parallélogramme, donc $\overrightarrow{DC} = \overrightarrow{AB} = \overrightarrow{CE}$.
3. $\overrightarrow{DC} = \overrightarrow{CE}$ : $C$ est le milieu de $[DE]$.
4. $\overrightarrow{AB} = \overrightarrow{CE}$ : $ABEC$ est un parallélogramme.
:::
:::

:::exercice Problème 2 : deux translations opposées
$ABC$ est un triangle. On note $D$ l’image de $A$ par la translation de vecteur $\overrightarrow{BC}$, et $E$ l’image de $A$ par la translation de vecteur $\overrightarrow{CB}$.

1. Écrire les égalités de vecteurs qui définissent $D$ et $E$.
2. Quelle est la nature des quadrilatères $ADCB$ et $AEBC$ ?
3. Montrer que $\overrightarrow{EA} = \overrightarrow{AD}$, et en déduire que $A$ est le milieu de $[DE]$.

:::corrige
1. $\overrightarrow{AD} = \overrightarrow{BC}$ et $\overrightarrow{AE} = \overrightarrow{CB}$.
2. $\overrightarrow{AD} = \overrightarrow{BC}$ : $ADCB$ est un parallélogramme. $\overrightarrow{AE} = \overrightarrow{CB}$ : $AEBC$ est un parallélogramme.
3. $\overrightarrow{EA} = -\overrightarrow{AE} = -\overrightarrow{CB} = \overrightarrow{BC} = \overrightarrow{AD}$ : $A$ est le milieu de $[DE]$.
:::
:::
