:::exercice Problème 1 : deux classes
Notes d’un devoir dans deux classes de $20$ élèves :

- classe A : $6$ (×$2$), $9$ (×$4$), $12$ (×$8$), $15$ (×$4$), $18$ (×$2$) ;
- classe B : $10$ (×$5$), $12$ (×$10$), $14$ (×$5$).

1. Calculer la moyenne de chaque classe.
2. Calculer la médiane et l’étendue de chaque classe.
3. Comparer les deux classes.

:::corrige
1. A : $\frac{12 + 36 + 96 + 60 + 36}{20} = 12$. B : $\frac{50 + 120 + 70}{20} = 12$.
2. A : effectifs cumulés $2$, $6$, $14$… ; les rangs $10$ et $11$ valent $12$, donc $Me = 12$ ; étendue $12$. B : cumulés $5$, $15$… ; $Me = 12$ ; étendue $4$.
3. Même moyenne et même médiane, mais la classe B est beaucoup plus homogène : son étendue est trois fois plus petite.
:::
:::

:::exercice Problème 2 : une note manquante
Un élève a obtenu cinq notes : $12$, $15$, $x$, $10$ et $14$. Sa moyenne est $13$.

1. Calculer $x$.
2. Quelle note doit-il obtenir au sixième devoir pour que sa moyenne passe à $14$ ?
3. Avec cette sixième note, quelle est la médiane de ses six notes ?

:::corrige
1. $\frac{51 + x}{5} = 13 \iff 51 + x = 65 \iff x = 14$.
2. $\frac{65 + y}{6} = 14 \iff 65 + y = 84 \iff y = 19$.
3. Rangées : $10$, $12$, $14$, $14$, $15$, $19$. Médiane : $\frac{14 + 14}{2} = 14$.
:::
:::
