Quatre exercices sur la deuxième partie du cours.

:::exercice Produits
Calculer : $(-7) \times (+8)$ ; $(-9) \times (-6)$ ; $(-1{,}5) \times 4$ ; $(-2) \times (-5) \times (-3)$.

:::corrige
$-56$ ; $54$ ; $-6$ ; $-30$.
:::
:::

:::exercice Quotients
Calculer : $\frac{-48}{-6}$ ; $\frac{63}{-9}$ ; $\frac{-4{,}5}{0{,}5}$.

:::corrige
$8$ ; $-7$ ; $-9$.
:::
:::

:::exercice Signe d’un produit
Sans calculer, donner le signe, puis calculer :

1. $(-2) \times (-3) \times (-4) \times (-5)$
2. $(-1) \times 2 \times (-3) \times 4 \times (-5)$

:::corrige
1. Quatre facteurs négatifs : positif, $120$.
2. Trois facteurs négatifs : négatif, $-120$.
:::
:::

:::exercice Priorités
Calculer :

1. $F = -3 + 4 \times (-2)$
2. $G = (-3 + 4) \times (-2)$
3. $H = 20 - 3 \times (-4) + (-18) \div 3$
4. $I = (-2) \times (-5 + 8) - (-12) \div (-4)$

:::corrige
1. $-3 - 8 = -11$.
2. $-2$.
3. $20 + 12 - 6 = 26$.
4. $(-2) \times 3 - 3 = -6 - 3 = -9$.
:::
:::
