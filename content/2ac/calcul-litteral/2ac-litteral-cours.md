## Expression littérale

:::definition
Une **expression littérale** contient des lettres qui représentent des nombres. Pour calculer sa **valeur numérique**, on remplace chaque lettre par un nombre.
:::

:::exemple
Pour $x = 2$ et $y = -1$ : $3x - 2y = 3 \times 2 - 2 \times (-1) = 6 + 2 = 8$.
:::

:::attention
On place des parenthèses autour d’un nombre négatif qu’on substitue : pour $x = -2$, $x^2 = (-2)^2 = 4$.
:::

## Réduire

:::propriete
**Réduire** une expression, c’est regrouper les termes semblables : les termes en $x$ ensemble, les termes en $x^2$ ensemble, les nombres ensemble.
:::

:::exemple
- $5x + 3 - 2x + 7 = 3x + 10$.
- $4x^2 - x + 2x^2 + 5x = 6x^2 + 4x$.
:::

## Développer

:::propriete
- **Distributivité simple** : $k(a + b) = ka + kb$ et $k(a - b) = ka - kb$.
- **Distributivité double** : $(a + b)(c + d) = ac + ad + bc + bd$.
:::

:::exemple
- $-3(2x - 4) = -6x + 12$.
- $(x + 4)(x - 1) = x^2 - x + 4x - 4 = x^2 + 3x - 4$.
- $(2a - 3)(a + 5) = 2a^2 + 10a - 3a - 15 = 2a^2 + 7a - 15$.
- $2(x + 3) - 3(x - 1) = 2x + 6 - 3x + 3 = -x + 9$.
:::

:::attention
$2x + 3$ ne se réduit pas en $5x$ : on n’additionne que des termes semblables.
:::
