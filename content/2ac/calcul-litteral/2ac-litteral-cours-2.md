## Factoriser avec un facteur commun

:::propriete
**Factoriser**, c’est écrire une somme sous forme de produit : $ka + kb = k(a + b)$.
:::

:::exemple
- $8x + 12 = 4(2x + 3)$.
- $3x^2 + 6x = 3x(x + 2)$.
- $(x + 2)(x - 3) + 4(x + 2) = (x + 2)\left[(x - 3) + 4\right] = (x + 2)(x + 1)$.
:::

## Les identités remarquables

:::propriete
Pour tous nombres $a$ et $b$ :

- $(a + b)^2 = a^2 + 2ab + b^2$ ;
- $(a - b)^2 = a^2 - 2ab + b^2$ ;
- $(a + b)(a - b) = a^2 - b^2$.
:::

:::exemple
- $(x + 3)^2 = x^2 + 6x + 9$.
- $(2a - 1)^2 = 4a^2 - 4a + 1$.
- $(y - 4)(y + 4) = y^2 - 16$.
:::

## Factoriser avec une identité

:::exemple
- $x^2 - 25 = (x - 5)(x + 5)$.
- $x^2 + 10x + 25 = (x + 5)^2$.
- $4y^2 - 4y + 1 = (2y - 1)^2$.
:::

:::attention
On vérifie une factorisation en développant : on doit retrouver l’expression de départ.
:::
