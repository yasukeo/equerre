Trois exercices sur la première partie du cours.

:::exercice Valeur numérique
Calculer $A = 2x^2 - 3x + 1$ pour $x = -2$, puis pour $x = \frac{1}{2}$.

:::corrige
- $x = -2$ : $8 + 6 + 1 = 15$.
- $x = \frac{1}{2}$ : $\frac{1}{2} - \frac{3}{2} + 1 = 0$.
:::
:::

:::exercice Réduire
Réduire : $B = 7a - 3 + 2a - 8$ et $C = 3x^2 + 2x - x^2 - 5x + 4$.

:::corrige
$B = 9a - 11$ ; $C = 2x^2 - 3x + 4$.
:::
:::

:::exercice Développer
Développer et réduire :

1. $D = 4(3x - 2)$
2. $E = -2(5 - x)$
3. $F = (x + 5)(x + 2)$
4. $G = (3x - 1)(2x + 4)$
5. $H = 2(x + 3) - 3(x - 1)$

:::corrige
1. $12x - 8$.
2. $-10 + 2x$.
3. $x^2 + 7x + 10$.
4. $6x^2 + 12x - 2x - 4 = 6x^2 + 10x - 4$.
5. $-x + 9$.
:::
:::
