Trois exercices sur la deuxième partie du cours.

:::exercice Facteur commun
Factoriser : $6x - 9$ ; $x^2 + 4x$ ; $5a^2b - 10ab$ ; $(x - 1)(2x + 3) - (x - 1)(x - 2)$.

:::corrige
$3(2x - 3)$ ; $x(x + 4)$ ; $5ab(a - 2)$ ; $(x - 1)\left[(2x + 3) - (x - 2)\right] = (x - 1)(x + 5)$.
:::
:::

:::exercice Développer avec les identités
Développer : $(a + 6)^2$ ; $(3x - 2)^2$ ; $(5 - y)(5 + y)$.

:::corrige
$a^2 + 12a + 36$ ; $9x^2 - 12x + 4$ ; $25 - y^2$.
:::
:::

:::exercice Factoriser avec les identités
Factoriser : $x^2 - 9$ ; $4x^2 - 1$ ; $x^2 + 10x + 25$ ; $9y^2 - 6y + 1$.

:::corrige
$(x - 3)(x + 3)$ ; $(2x - 1)(2x + 1)$ ; $(x + 5)^2$ ; $(3y - 1)^2$.
:::
:::
