Durée : une heure. Le repère est orthonormé.

:::exercice Exercice 1 (6 points) : orthogonalité
$A(1 ; 2 ; 0)$, $B(3 ; 0 ; 1)$, $C(2 ; 4 ; 2)$. Montrer que le triangle $ABC$ est rectangle en $A$ et calculer son aire.

:::corrige
$\overrightarrow{AB}(2 ; -2 ; 1)$, $\overrightarrow{AC}(1 ; 2 ; 2)$ : $2 - 4 + 2 = 0$. $AB = AC = 3$ ; aire $= \frac{9}{2}$.
:::
:::

:::exercice Exercice 2 (7 points) : plan et distance
1. Équation du plan $(P)$ passant par $A(1 ; 2 ; 0)$ et de vecteur normal $\overrightarrow{AB}$ (points de l’exercice 1). (3 pts)
2. Distance de $C$ à $(P)$. (4 pts)

:::corrige
1. $2x - 2y + z + d = 0$ avec $2 - 4 + d = 0$ : $2x - 2y + z + 2 = 0$.
2. $\frac{|4 - 8 + 2 + 2|}{3} = 0$ : $C$ est dans $(P)$ (normal : $\overrightarrow{AC} \perp \overrightarrow{AB}$).
:::
:::

:::exercice Exercice 3 (7 points) : sphère et plan
$(S) : x^2 + y^2 + z^2 = 25$ et $(Q) : 3x + 4z - 15 = 0$.

1. Calculer la distance de $O$ à $(Q)$. (3 pts)
2. En déduire la nature de l’intersection de $(S)$ et $(Q)$. (4 pts)

:::corrige
1. $\frac{15}{5} = 3$.
2. $3 < 5$ : cercle de rayon $4$, de centre le projeté de $O$ : $t(3 ; 0 ; 4)$ avec $25t = 15$, $t = \frac{3}{5}$, centre $\left(\frac{9}{5} ; 0 ; \frac{12}{5}\right)$.
:::
:::
