## Vocabulaire

- $D_f$ : dénominateur $\neq 0$, ce qui est sous une racine $\geq 0$.
- **Paire** : $f(-x) = f(x)$ (symétrie par rapport à l’axe des ordonnées) ; **impaire** : $f(-x) = -f(x)$ (symétrie par rapport à $O$).
- **Majorée** par $M$, **minorée** par $m$, **bornée** ; maximum et minimum.
- **Variations** : signe du taux $\frac{f(b) - f(a)}{b - a}$.
- **Composée** $g \circ f$ : croissante si $f$ et $g$ ont le même sens, décroissante sinon.

## Fonctions de référence

:::propriete
- Trinôme : $a(x - \alpha)^2 + \beta$, $\alpha = -\frac{b}{2a}$ ; parabole de sommet $(\alpha ; \beta)$.
- Homographique : $\beta + \frac{k}{x - \alpha}$ ; centre $(\alpha ; \beta)$, asymptotes $x = \alpha$ et $y = \beta$ ; décroissante par morceaux si $k > 0$.
- $x^3$ : impaire, croissante ; $\sqrt{x + a}$ : croissante sur $[-a ; +\infty[$.
:::

## Symétries

Axe $x = a$ : $f(2a - x) = f(x)$. Centre $\Omega(a ; b)$ : $f(2a - x) + f(x) = 2b$.

:::attention
Pour la parité, on vérifie d’abord que $D_f$ est symétrique par rapport à $0$.
:::
