## Formules

:::propriete
- $\cos(a \pm b) = \cos a\cos b \mp \sin a\sin b$ ; $\sin(a \pm b) = \sin a\cos b \pm \cos a\sin b$.
- $\sin 2a = 2\sin a\cos a$ ; $\cos 2a = 2\cos^2 a - 1 = 1 - 2\sin^2 a$.
- $\cos^2 a = \frac{1 + \cos 2a}{2}$, $\sin^2 a = \frac{1 - \cos 2a}{2}$.
- $a\cos x + b\sin x = r\cos(x - \varphi)$ avec $r = \sqrt{a^2 + b^2}$, $\cos\varphi = \frac{a}{r}$, $\sin\varphi = \frac{b}{r}$.
:::

## Équations

:::propriete
- $\cos x = \cos a \iff x = \pm a + 2k\pi$.
- $\sin x = \sin a \iff x = a + 2k\pi$ ou $x = \pi - a + 2k\pi$.
- $\tan x = \tan a \iff x = a + k\pi$.
:::

Second degré : poser $X = \cos x$ ou $X = \sin x$ (avec $-1 \leq X \leq 1$). Inéquations : lire sur le cercle trigonométrique.

:::attention
Quand on résout $\cos(nx) = \cos a$, on divise aussi $2k\pi$ par $n$. Et on ne garde que les valeurs de $X = \cos x$ comprises entre $-1$ et $1$.
:::
