Quatre exercices sur la deuxième partie du cours.

:::exercice Équations fondamentales
Résoudre dans $\mathbb{R}$, puis donner les solutions dans $[0 ; 2\pi[$ :

1. $\sin x = \dfrac{\sqrt{3}}{2}$
2. $\cos\left(2x - \dfrac{\pi}{3}\right) = 0$
3. $\tan x = -1$

:::corrige
1. $x = \frac{\pi}{3} + 2k\pi$ ou $x = \frac{2\pi}{3} + 2k\pi$ ; dans $[0 ; 2\pi[$ : $\frac{\pi}{3}$ et $\frac{2\pi}{3}$.
2. $2x - \frac{\pi}{3} = \frac{\pi}{2} + k\pi$, donc $x = \frac{5\pi}{12} + \frac{k\pi}{2}$ ; dans $[0 ; 2\pi[$ : $\frac{5\pi}{12}$, $\frac{11\pi}{12}$, $\frac{17\pi}{12}$, $\frac{23\pi}{12}$.
3. $x = -\frac{\pi}{4} + k\pi$ ; dans $[0 ; 2\pi[$ : $\frac{3\pi}{4}$ et $\frac{7\pi}{4}$.
:::
:::

:::exercice a cos x + b sin x = c
Résoudre dans $\mathbb{R}$ l’équation $\sqrt{3}\cos x + \sin x = \sqrt{2}$.

:::corrige
$\sqrt{3}\cos x + \sin x = 2\cos\left(x - \frac{\pi}{6}\right)$. L’équation devient $\cos\left(x - \frac{\pi}{6}\right) = \frac{\sqrt{2}}{2} = \cos\frac{\pi}{4}$ : $x = \frac{\pi}{6} \pm \frac{\pi}{4} + 2k\pi$, soit $x = \frac{5\pi}{12} + 2k\pi$ ou $x = -\frac{\pi}{12} + 2k\pi$.
:::
:::

:::exercice Second degré
Résoudre dans $[0 ; 2\pi[$ :

1. $2\sin^2 x + \sin x - 1 = 0$
2. $\cos 2x = 3\cos x - 2$

:::corrige
1. $X = \sin x$ : $2X^2 + X - 1 = 0$, $X = \frac{1}{2}$ ou $X = -1$. $S = \left\{\frac{\pi}{6} ; \frac{5\pi}{6} ; \frac{3\pi}{2}\right\}$.
2. $2\cos^2 x - 1 = 3\cos x - 2$, soit $2X^2 - 3X + 1 = 0$ avec $X = \cos x$ : $X = 1$ ou $X = \frac{1}{2}$. $S = \left\{0 ; \frac{\pi}{3} ; \frac{5\pi}{3}\right\}$.
:::
:::

:::exercice Inéquations
Résoudre dans $[0 ; 2\pi[$ :

1. $\cos x < \dfrac{\sqrt{3}}{2}$
2. $2\sin x - 1 \geq 0$

:::corrige
1. Les points d’abscisse inférieure à $\frac{\sqrt{3}}{2}$ : $S = \left]\frac{\pi}{6} ; \frac{11\pi}{6}\right[$.
2. $\sin x \geq \frac{1}{2}$ : $S = \left[\frac{\pi}{6} ; \frac{5\pi}{6}\right]$.
:::
:::
