Durée : une heure.

:::exercice Exercice 1 (6 points) : formules
1. Calculer $\cos\dfrac{\pi}{12}$ et $\sin\dfrac{\pi}{12}$. (3 pts)
2. Sachant que $\sin a = \frac{1}{3}$ et $a \in \left]\frac{\pi}{2} ; \pi\right[$, calculer $\cos a$ et $\sin 2a$. (3 pts)

:::corrige
1. $\cos\left(\frac{\pi}{3} - \frac{\pi}{4}\right) = \frac{\sqrt{2} + \sqrt{6}}{4}$ ; $\sin\left(\frac{\pi}{3} - \frac{\pi}{4}\right) = \frac{\sqrt{3}}{2} \times \frac{\sqrt{2}}{2} - \frac{1}{2} \times \frac{\sqrt{2}}{2} = \frac{\sqrt{6} - \sqrt{2}}{4}$.
2. $\cos^2 a = \frac{8}{9}$ et $\cos a < 0$ : $\cos a = -\frac{2\sqrt{2}}{3}$. $\sin 2a = 2 \times \frac{1}{3} \times \left(-\frac{2\sqrt{2}}{3}\right) = -\frac{4\sqrt{2}}{9}$.
:::
:::

:::exercice Exercice 2 (4 points) : identité
Montrer que pour tout réel $x$ tel que $\cos x \neq 0$ : $\dfrac{\sin 2x}{1 + \cos 2x} = \tan x$.

:::corrige
$\frac{2\sin x\cos x}{1 + 2\cos^2 x - 1} = \frac{2\sin x\cos x}{2\cos^2 x} = \frac{\sin x}{\cos x} = \tan x$.
:::
:::

:::exercice Exercice 3 (10 points) : équations et inéquation
1. Résoudre dans $\mathbb{R}$ : $\cos\left(x + \dfrac{\pi}{4}\right) = \dfrac{1}{2}$. (3 pts)
2. Résoudre dans $[0 ; 2\pi[$ : $2\cos^2 x + 3\cos x + 1 = 0$. (4 pts)
3. Résoudre dans $[-\pi ; \pi]$ : $\sin x > \dfrac{1}{2}$. (3 pts)

:::corrige
1. $x + \frac{\pi}{4} = \pm\frac{\pi}{3} + 2k\pi$ : $x = \frac{\pi}{12} + 2k\pi$ ou $x = -\frac{7\pi}{12} + 2k\pi$.
2. $X = \cos x$ : $2X^2 + 3X + 1 = 0$, $X = -1$ ou $X = -\frac{1}{2}$ : $S = \left\{\pi ; \frac{2\pi}{3} ; \frac{4\pi}{3}\right\}$.
3. $S = \left]\frac{\pi}{6} ; \frac{5\pi}{6}\right[$.
:::
:::
