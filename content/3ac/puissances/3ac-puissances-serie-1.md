Trois exercices sur la première partie du cours.

:::exercice Calculer
Calculer : $2^4$ ; $(-2)^4$ ; $-2^4$ ; $(-1)^7$ ; $10^{-3}$ ; $\left(\frac{1}{2}\right)^3$ ; $3^{-2}$.

:::corrige
$16$ ; $16$ ; $-16$ ; $-1$ ; $0{,}001$ ; $\frac{1}{8}$ ; $\frac{1}{9}$.
:::
:::

:::exercice Simplifier
Écrire sous la forme d’une seule puissance ou d’un monôme :

1. $a^2 \times a^5$
2. $\dfrac{a^8}{a^3}$
3. $(a^3)^2$
4. $(-2a^2)^3$
5. $a^{-2} \times a^5$

:::corrige
1. $a^7$.
2. $a^5$.
3. $a^6$.
4. $-8a^6$.
5. $a^3$.
:::
:::

:::exercice Calculer astucieusement
Calculer :

1. $A = \dfrac{3^2 \times 3^5}{3^4}$
2. $B = (2^3)^2 \times 2^{-5}$
3. $C = 5^{-1} \times 5^3$
4. $D = \dfrac{2^5 \times 5^5}{10^3}$

:::corrige
1. $3^3 = 27$.
2. $2^{6 - 5} = 2$.
3. $5^2 = 25$.
4. $\frac{10^5}{10^3} = 10^2 = 100$.
:::
:::
