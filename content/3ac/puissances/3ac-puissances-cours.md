## Définition

:::definition
Pour un nombre $a$ et un entier $n \geq 1$, $a^n = a \times a \times \cdots \times a$ ($n$ facteurs). Pour $a \neq 0$ : $a^0 = 1$ et $a^{-n} = \frac{1}{a^n}$.
:::

:::exemple
$2^5 = 32$ ; $10^3 = 1\,000$ ; $5^{-2} = \frac{1}{25}$ ; $10^{-3} = 0{,}001$ ; $\left(\frac{1}{2}\right)^3 = \frac{1}{8}$.
:::

## Signe d’une puissance

:::propriete
Pour $a > 0$ : $(-a)^n$ est positif si $n$ est pair, négatif si $n$ est impair.
:::

:::exemple
$(-3)^2 = 9$ et $(-3)^3 = -27$. Mais $-3^2 = -9$ : sans parenthèses, seul $3$ est élevé au carré.
:::

## Règles de calcul

:::propriete
Pour $a \neq 0$, $b \neq 0$, et $m$, $n$ entiers relatifs :

- $a^m \times a^n = a^{m + n}$ ;
- $\frac{a^m}{a^n} = a^{m - n}$ ;
- $(a^m)^n = a^{m \times n}$ ;
- $(ab)^n = a^n \times b^n$ et $\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$.
:::

:::exemple
- $a^3 \times a^4 = a^7$ ; $\frac{a^7}{a^2} = a^5$ ; $(a^2)^3 = a^6$.
- $(2a)^3 = 8a^3$ ; $(-2a^2)^3 = -8a^6$.
- $\frac{3^2 \times 3^5}{3^4} = 3^{2 + 5 - 4} = 3^3 = 27$.
:::

:::attention
$a^m + a^n$ ne se simplifie pas en $a^{m + n}$ : $2^2 + 2^3 = 4 + 8 = 12$, alors que $2^5 = 32$.
:::
