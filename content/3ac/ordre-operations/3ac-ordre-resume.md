## Règles

:::propriete
- $a < b \iff a - b < 0$.
- Ajouter un nombre : même sens. Multiplier par un positif : même sens ; par un négatif : le sens change.
- Additionner deux inégalités de même sens : oui. Multiplier : seulement si tout est positif.
- Pour $a, b > 0$ : $a < b \iff a^2 < b^2 \iff \sqrt{a} < \sqrt{b} \iff \frac{1}{a} > \frac{1}{b}$.
:::

## Valeurs approchées

Troncature : on coupe. Arrondi : on garde la valeur la plus proche.

:::attention
Pour encadrer $x - y$ : encadrer $-y$, puis additionner.
:::
