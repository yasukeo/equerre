## Comparer deux nombres

:::propriete
Pour comparer $a$ et $b$, on étudie le signe de $a - b$ : si $a - b > 0$, alors $a > b$ ; si $a - b < 0$, alors $a < b$ ; si $a - b = 0$, alors $a = b$.
:::

:::exemple
- $\frac{3}{4} + \frac{1}{5} - 1 = \frac{15 + 4 - 20}{20} = -\frac{1}{20} < 0$, donc $\frac{3}{4} + \frac{1}{5} < 1$.
- Pour tout nombre $x$ : $x^2 + 1 - 2x = (x - 1)^2 \geq 0$, donc $x^2 + 1 \geq 2x$.
:::

## Ordre et addition

:::propriete
Si $a < b$, alors $a + c < b + c$ et $a - c < b - c$, pour tout nombre $c$.
:::

## Ordre et multiplication

:::propriete
Si $a < b$ :

- pour $k > 0$, $ka < kb$ : le sens ne change pas ;
- pour $k < 0$, $ka > kb$ : le sens **change**.
:::

:::exemple
Si $a < b$, alors $a - 3 < b - 3$, $4a < 4b$ et $-5a > -5b$. Donc $2 - 5a > 2 - 5b$.
:::

## Additionner et multiplier des inégalités

:::propriete
- Si $a < b$ et $c < d$, alors $a + c < b + d$.
- Si $a$, $b$, $c$, $d$ sont **positifs**, avec $a < b$ et $c < d$, alors $ac < bd$.
:::

:::exemple
Si $2 < x < 3$ et $1 < y < 4$ :

- $3 < x + y < 7$ ;
- $2 < xy < 12$ (tous les nombres sont positifs) ;
- $-4 < -y < -1$, donc $-2 < x - y < 2$.
:::

:::attention
On ne soustrait jamais deux inégalités membre à membre : pour encadrer $x - y$, on encadre d’abord $-y$, puis on additionne.
:::
