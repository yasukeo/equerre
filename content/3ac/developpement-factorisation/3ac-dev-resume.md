## Développer

:::propriete
- $k(a + b) = ka + kb$ ; $(a + b)(c + d) = ac + ad + bc + bd$.
- $(a + b)^2 = a^2 + 2ab + b^2$ ; $(a - b)^2 = a^2 - 2ab + b^2$ ; $(a + b)(a - b) = a^2 - b^2$.
:::

## Factoriser

:::propriete
- Facteur commun : $ka + kb = k(a + b)$.
- Identités lues à l’envers : $a^2 - b^2 = (a + b)(a - b)$, etc.
:::

:::attention
Un « $-$ » devant une parenthèse change tous les signes ; on vérifie une factorisation en la développant.
:::
