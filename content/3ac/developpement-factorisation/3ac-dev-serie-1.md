Trois exercices sur la première partie du cours.

:::exercice Distributivité
Développer et réduire :

1. $3(2x - 5)$
2. $-2(x - 4)$
3. $(x + 3)(x - 2)$
4. $(2x - 1)(3x + 4)$

:::corrige
1. $6x - 15$.
2. $-2x + 8$.
3. $x^2 + x - 6$.
4. $6x^2 + 8x - 3x - 4 = 6x^2 + 5x - 4$.
:::
:::

:::exercice Identités remarquables
Développer :

1. $(x + 5)^2$
2. $(3x - 2)^2$
3. $(2x + 7)(2x - 7)$
4. $\left(\frac{1}{2}x + 4\right)^2$

:::corrige
1. $x^2 + 10x + 25$.
2. $9x^2 - 12x + 4$.
3. $4x^2 - 49$.
4. $\frac{1}{4}x^2 + 4x + 16$.
:::
:::

:::exercice Développer et réduire
Développer et réduire :

1. $A = (x + 2)^2 - (x - 1)(x + 1)$
2. $B = (2x - 3)^2 - 4x(x - 3)$
3. $C = (x + 4)(x - 4) - (x - 4)^2$

:::corrige
1. $x^2 + 4x + 4 - x^2 + 1 = 4x + 5$.
2. $4x^2 - 12x + 9 - 4x^2 + 12x = 9$.
3. $x^2 - 16 - (x^2 - 8x + 16) = 8x - 32$.
:::
:::
