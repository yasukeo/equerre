Trois exercices sur la deuxième partie du cours.

:::exercice Facteur commun
Factoriser :

1. $7x + 14$
2. $x^2 - 5x$
3. $(x + 1)(2x - 3) + (x + 1)(x + 4)$
4. $(2x - 1)^2 - (2x - 1)(x + 3)$

:::corrige
1. $7(x + 2)$.
2. $x(x - 5)$.
3. $(x + 1)(3x + 1)$.
4. $(2x - 1)\left[(2x - 1) - (x + 3)\right] = (2x - 1)(x - 4)$.
:::
:::

:::exercice Identités remarquables
Factoriser :

1. $x^2 - 36$
2. $9x^2 - 4$
3. $x^2 + 8x + 16$
4. $25x^2 - 10x + 1$
5. $(x - 3)^2 - 16$

:::corrige
1. $(x - 6)(x + 6)$.
2. $(3x - 2)(3x + 2)$.
3. $(x + 4)^2$.
4. $(5x - 1)^2$.
5. $(x - 7)(x + 1)$.
:::
:::

:::exercice Calcul mental
Calculer sans calculatrice, en utilisant une identité remarquable : $102^2$ ; $49^2$ ; $51 \times 49$ ; $1\,003 \times 997$.

:::corrige
- $(100 + 2)^2 = 10\,404$.
- $(50 - 1)^2 = 2\,500 - 100 + 1 = 2\,401$.
- $(50 + 1)(50 - 1) = 2\,499$.
- $(1\,000 + 3)(1\,000 - 3) = 1\,000\,000 - 9 = 999\,991$.
:::
:::
