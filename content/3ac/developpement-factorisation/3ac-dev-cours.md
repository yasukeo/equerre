## Distributivité

:::propriete
Pour tous nombres $k$, $a$, $b$, $c$, $d$ :

- $k(a + b) = ka + kb$ et $k(a - b) = ka - kb$ ;
- $(a + b)(c + d) = ac + ad + bc + bd$.
:::

:::exemple
- $3(2x - 5) = 6x - 15$.
- $-2(x - 4) = -2x + 8$.
- $(x + 3)(x - 2) = x^2 - 2x + 3x - 6 = x^2 + x - 6$.
:::

## Les identités remarquables

:::propriete
Pour tous nombres $a$ et $b$ :

- $(a + b)^2 = a^2 + 2ab + b^2$ ;
- $(a - b)^2 = a^2 - 2ab + b^2$ ;
- $(a + b)(a - b) = a^2 - b^2$.
:::

:::exemple
- $(x + 5)^2 = x^2 + 2 \times x \times 5 + 25 = x^2 + 10x + 25$.
- $(3x - 2)^2 = 9x^2 - 12x + 4$.
- $(2x + 7)(2x - 7) = 4x^2 - 49$.
:::

:::attention
$(a + b)^2 \neq a^2 + b^2$ : il ne faut pas oublier le double produit $2ab$. Par exemple $(3 + 4)^2 = 49$, alors que $3^2 + 4^2 = 25$.
:::

## Développer et réduire

:::exemple
$A = (x + 2)^2 - (x - 1)(x + 1) = x^2 + 4x + 4 - (x^2 - 1) = x^2 + 4x + 4 - x^2 + 1 = 4x + 5$.
:::

:::attention
Un signe « $-$ » devant une parenthèse change tous les signes à l’intérieur : $-(x^2 - 1) = -x^2 + 1$.
:::
