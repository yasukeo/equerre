## Factoriser avec un facteur commun

:::propriete
Factoriser, c’est transformer une somme en produit : $ka + kb = k(a + b)$. On repère un **facteur commun** à tous les termes.
:::

:::exemple
- $7x + 14 = 7(x + 2)$.
- $x^2 - 5x = x(x - 5)$.
- $(x + 1)(2x - 3) + (x + 1)(x + 4) = (x + 1)\left[(2x - 3) + (x + 4)\right] = (x + 1)(3x + 1)$.
:::

## Factoriser avec une identité remarquable

:::propriete
On lit les identités « de droite à gauche » :

- $a^2 + 2ab + b^2 = (a + b)^2$ ;
- $a^2 - 2ab + b^2 = (a - b)^2$ ;
- $a^2 - b^2 = (a + b)(a - b)$.
:::

:::exemple
- $x^2 - 36 = (x - 6)(x + 6)$.
- $9x^2 - 4 = (3x)^2 - 2^2 = (3x - 2)(3x + 2)$.
- $x^2 + 8x + 16 = (x + 4)^2$.
- $(x - 3)^2 - 16 = \left[(x - 3) - 4\right]\left[(x - 3) + 4\right] = (x - 7)(x + 1)$.
:::

## Calculer de tête

:::exemple
- $99^2 = (100 - 1)^2 = 10\,000 - 200 + 1 = 9\,801$.
- $102^2 = (100 + 2)^2 = 10\,000 + 400 + 4 = 10\,404$.
- $51 \times 49 = (50 + 1)(50 - 1) = 2\,500 - 1 = 2\,499$.
:::

:::attention
Pour vérifier une factorisation, on développe le résultat : on doit retrouver l’expression de départ.
:::
