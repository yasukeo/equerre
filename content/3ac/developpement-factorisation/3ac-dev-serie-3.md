:::exercice Problème 1 : une expression
Soit $E = (2x - 3)^2 - (x + 1)(2x - 3)$.

1. Développer et réduire $E$.
2. Factoriser $E$.
3. Calculer $E$ pour $x = 0$, puis pour $x = 4$, en choisissant la forme la plus pratique.

:::corrige
1. $4x^2 - 12x + 9 - (2x^2 - 3x + 2x - 3) = 4x^2 - 12x + 9 - 2x^2 + x + 3 = 2x^2 - 11x + 12$.
2. $(2x - 3)\left[(2x - 3) - (x + 1)\right] = (2x - 3)(x - 4)$.
3. Pour $x = 0$, la forme développée donne $12$. Pour $x = 4$, la forme factorisée donne $5 \times 0 = 0$.
:::
:::

:::exercice Problème 2 : des carrés consécutifs
Soit $n$ un nombre entier.

1. Montrer que $(n + 1)^2 - n^2 = 2n + 1$.
2. En déduire, sans calculatrice, $1\,001^2 - 1\,000^2$.
3. Montrer que $n^2 - (n - 1)(n + 1) = 1$.
4. Vérifier cette égalité avec $n = 25$.

:::corrige
1. $n^2 + 2n + 1 - n^2 = 2n + 1$.
2. Avec $n = 1\,000$ : $2\,001$.
3. $n^2 - (n^2 - 1) = 1$.
4. $25^2 - 24 \times 26 = 625 - 624 = 1$.
:::
:::
