## Équation du premier degré

:::propriete
Pour résoudre une équation, on peut ajouter ou soustraire un même nombre aux deux membres, et les multiplier ou les diviser par un même nombre **non nul**. On isole ainsi l’inconnue.
:::

:::exemple
- $5x - 4 = 2x + 11 \iff 3x = 15 \iff x = 5$.
- $4(x - 3) - 2(x + 1) = 0 \iff 4x - 12 - 2x - 2 = 0 \iff 2x = 14 \iff x = 7$.
:::

:::attention
Une équation peut n’avoir aucune solution ($x + 1 = x + 3$) ou en avoir une infinité ($2x + 4 = 2(x + 2)$).
:::

## Équation produit nul

:::propriete
Un produit est nul si et seulement si l’un au moins de ses facteurs est nul : $A \times B = 0 \iff A = 0$ ou $B = 0$.
:::

:::exemple
$(2x - 6)(x + 5) = 0 \iff 2x - 6 = 0$ ou $x + 5 = 0 \iff x = 3$ ou $x = -5$.
:::

## Factoriser pour résoudre

:::exemple
- $x^2 - 3x = 0 \iff x(x - 3) = 0 \iff x = 0$ ou $x = 3$.
- $4x^2 - 9 = 0 \iff (2x - 3)(2x + 3) = 0 \iff x = \frac{3}{2}$ ou $x = -\frac{3}{2}$.
- $x^2 = 7 \iff x = \sqrt{7}$ ou $x = -\sqrt{7}$.
:::

## Mettre un problème en équation

:::propriete
On choisit l’inconnue, on traduit l’énoncé par une équation, on la résout, puis on vérifie et on conclut par une phrase.
:::

:::exemple
La somme de trois entiers consécutifs vaut $72$. Avec $n$ le plus petit : $n + (n + 1) + (n + 2) = 72 \iff 3n + 3 = 72 \iff n = 23$. Les nombres sont $23$, $24$ et $25$.
:::
