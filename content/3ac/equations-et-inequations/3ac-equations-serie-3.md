:::exercice Problème 1 : même aire
Un carré a pour côté $x + 3$ (en cm), et un rectangle a pour dimensions $x + 1$ et $x + 7$, avec $x > 0$.

1. Exprimer l’aire du carré et celle du rectangle sous forme développée.
2. Pour quelle valeur de $x$ ont-ils la même aire ?
3. Donner alors les dimensions des deux figures, et vérifier.

:::corrige
1. Carré : $(x + 3)^2 = x^2 + 6x + 9$. Rectangle : $(x + 1)(x + 7) = x^2 + 8x + 7$.
2. $x^2 + 6x + 9 = x^2 + 8x + 7 \iff 2 = 2x \iff x = 1$.
3. Carré de côté $4$ cm ; rectangle de $2$ cm sur $8$ cm. Les deux aires valent $16$ cm².
:::
:::

:::exercice Problème 2 : deux abonnements
Une piscine propose deux tarifs : tarif A, un abonnement annuel de $200$ dirhams puis $10$ dirhams par entrée ; tarif B, $25$ dirhams par entrée, sans abonnement.

1. Exprimer le prix de chaque tarif pour $x$ entrées.
2. Résoudre l’équation $200 + 10x = 25x$. Que représente la solution ?
3. À partir de combien d’entrées le tarif A est-il plus avantageux ?

:::corrige
1. A : $200 + 10x$ ; B : $25x$.
2. $15x = 200$, $x = \frac{40}{3} \approx 13{,}3$ : les deux tarifs seraient égaux pour environ $13{,}3$ entrées, ce qui n’est pas un nombre entier.
3. $200 + 10x < 25x \iff x > \frac{40}{3}$ : à partir de $14$ entrées.
:::
:::
