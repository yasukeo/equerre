Quatre exercices sur la première partie du cours.

:::exercice Vecteurs égaux
$ABCD$ est un parallélogramme. Citer un vecteur égal à $\overrightarrow{AB}$, à $\overrightarrow{AD}$, à $\overrightarrow{BA}$ et à $\overrightarrow{DA}$.

:::corrige
$\overrightarrow{AB} = \overrightarrow{DC}$ ; $\overrightarrow{AD} = \overrightarrow{BC}$ ; $\overrightarrow{BA} = \overrightarrow{CD}$ ; $\overrightarrow{DA} = \overrightarrow{CB}$.
:::
:::

:::exercice Chasles
Simplifier :

1. $\overrightarrow{AB} + \overrightarrow{BC}$
2. $\overrightarrow{MN} + \overrightarrow{NP} + \overrightarrow{PM}$
3. $\overrightarrow{AB} - \overrightarrow{CB}$
4. $\overrightarrow{DE} + \overrightarrow{FD} + \overrightarrow{EF}$

:::corrige
1. $\overrightarrow{AC}$.
2. $\vec{0}$.
3. $\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$.
4. $\overrightarrow{FD} + \overrightarrow{DE} + \overrightarrow{EF} = \overrightarrow{FF} = \vec{0}$.
:::
:::

:::exercice Milieu
$I$ est le milieu de $[AB]$.

1. Citer un vecteur égal à $\overrightarrow{AI}$.
2. Que vaut $\overrightarrow{IA} + \overrightarrow{IB}$ ?

:::corrige
1. $\overrightarrow{IB}$.
2. $\overrightarrow{IA}$ et $\overrightarrow{IB}$ sont opposés : la somme est $\vec{0}$.
:::
:::

:::exercice Règle du parallélogramme
$ABC$ est un triangle. On construit le point $M$ tel que $\overrightarrow{AM} = \overrightarrow{AB} + \overrightarrow{AC}$.

1. Quelle est la nature du quadrilatère $ABMC$ ?
2. Montrer que $\overrightarrow{BM} = \overrightarrow{AC}$.

:::corrige
1. D’après la règle du parallélogramme, $ABMC$ est un parallélogramme.
2. Dans le parallélogramme $ABMC$, les côtés $[BM]$ et $[AC]$ sont opposés et de même sens : $\overrightarrow{BM} = \overrightarrow{AC}$.
:::
:::
