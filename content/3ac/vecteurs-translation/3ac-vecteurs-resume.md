## Vecteurs

:::propriete
- Direction, sens, longueur.
- $\overrightarrow{AB} = \overrightarrow{DC} \iff ABCD$ parallélogramme.
- $I$ milieu de $[AB] \iff \overrightarrow{AI} = \overrightarrow{IB}$.
- Chasles : $\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$ ; parallélogramme $ABDC$ : $\overrightarrow{AB} + \overrightarrow{AC} = \overrightarrow{AD}$.
:::

## Translation

:::propriete
- $M'$ image de $M$ : $\overrightarrow{MM'} = \vec{u}$.
- Conserve longueurs, angles, alignement, parallélisme, aires ; droite $\to$ droite parallèle.
- Deux translations à la suite : translation de vecteur $\vec{u} + \vec{v}$.
:::

:::attention
Attention à l’ordre des lettres : $\overrightarrow{AB} = \overrightarrow{DC}$ correspond au parallélogramme $ABCD$, pas $ABDC$.
:::
