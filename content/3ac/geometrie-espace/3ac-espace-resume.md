## Formules

:::propriete
- Pyramide : $V = \frac{1}{3}\mathcal{B}h$. Cône : $V = \frac{1}{3}\pi r^2 h$, génératrice $g^2 = r^2 + h^2$.
- Sphère : aire $4\pi r^2$. Boule : volume $\frac{4}{3}\pi r^3$.
:::

## Agrandissement et réduction

:::propriete
- Longueurs $\times k$, aires $\times k^2$, volumes $\times k^3$.
- Section parallèle à la base d’une pyramide ou d’un cône : réduction de rapport $k = \frac{h'}{h}$.
:::

:::attention
Les unités : cm pour les longueurs, cm² pour les aires, cm³ pour les volumes.
:::
