## Coordonnées d’un vecteur

:::propriete
Pour $A(x_A ; y_A)$ et $B(x_B ; y_B)$, le vecteur $\overrightarrow{AB}$ a pour coordonnées $(x_B - x_A ; y_B - y_A)$ : « arrivée moins départ ».
:::

:::exemple
$A(2 ; 3)$ et $B(6 ; 1)$ : $\overrightarrow{AB}(4 ; -2)$.
:::

## Vecteurs égaux et parallélogramme

:::propriete
- Deux vecteurs sont égaux si et seulement s’ils ont les mêmes coordonnées.
- $ABCD$ est un parallélogramme si et seulement si $\overrightarrow{AB} = \overrightarrow{DC}$.
:::

:::exemple
$A(1 ; 2)$, $B(5 ; 3)$, $C(6 ; 6)$. On cherche $D(x ; y)$ tel que $ABCD$ soit un parallélogramme : $\overrightarrow{AB}(4 ; 1)$ et $\overrightarrow{DC}(6 - x ; 6 - y)$. Donc $6 - x = 4$ et $6 - y = 1$ : $D(2 ; 5)$.
:::

## Opérations

:::propriete
Si $\vec{u}(a ; b)$ et $\vec{v}(a' ; b')$ :

- $\vec{u} + \vec{v}$ a pour coordonnées $(a + a' ; b + b')$ ;
- $k\vec{u}$ a pour coordonnées $(ka ; kb)$.
:::

:::exemple
$\vec{u}(2 ; -1)$ et $\vec{v}(-3 ; 4)$ : $\vec{u} + \vec{v}(-1 ; 3)$ et $3\vec{u}(6 ; -3)$.
:::

:::attention
Les coordonnées d’un vecteur se calculent « arrivée moins départ » : $\overrightarrow{BA}$ a les coordonnées opposées de $\overrightarrow{AB}$.
:::
