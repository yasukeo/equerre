Quatre exercices sur la deuxième partie du cours.

:::exercice Une série d’effectifs
Pointures des $40$ élèves : $37$ (×$4$), $38$ (×$10$), $39$ (×$12$), $40$ (×$8$), $41$ (×$6$). Calculer la moyenne, la médiane, le mode et l’étendue.

:::corrige
Moyenne : $\frac{148 + 380 + 468 + 320 + 246}{40} = \frac{1\,562}{40} = 39{,}05$. Médiane : rangs $20$ et $21$ ; les effectifs cumulés sont $4$, $14$, $26$…, donc ces deux rangs correspondent à $39$ : $Me = 39$. Mode $39$ ; étendue $4$.
:::
:::

:::exercice Une liste de valeurs
Notes d’un élève : $12$, $15$, $9$, $14$, $10$, $13$, $11$. Calculer la moyenne et la médiane.

:::corrige
Moyenne $\frac{84}{7} = 12$. Rangées : $9$, $10$, $11$, $12$, $13$, $14$, $15$ : la médiane est la $4^{\text{e}}$ valeur, $12$.
:::
:::

:::exercice Une série en classes
Âges des $50$ membres d’un club : $[10 ; 20[$ : $12$ ; $[20 ; 30[$ : $18$ ; $[30 ; 40[$ : $15$ ; $[40 ; 50[$ : $5$. Calculer l’âge moyen et donner la classe modale.

:::corrige
Centres : $15$, $25$, $35$, $45$. Moyenne : $\frac{180 + 450 + 525 + 225}{50} = \frac{1\,380}{50} = 27{,}6$ ans. Classe modale : $[20 ; 30[$.
:::
:::

:::exercice Une valeur extrême
Salaires de cinq employés : $3\,000$, $3\,200$, $3\,500$, $3\,800$ et $15\,000$ dirhams.

1. Calculer la moyenne et la médiane.
2. Lequel de ces deux nombres décrit le mieux le salaire « typique » ?

:::corrige
1. Moyenne $5\,700$ dirhams ; médiane $3\,500$ dirhams.
2. La médiane : quatre salaires sur cinq sont inférieurs à la moyenne, qui est tirée vers le haut par le salaire de $15\,000$ dirhams.
:::
:::
