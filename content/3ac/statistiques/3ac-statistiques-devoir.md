Durée : une heure.

:::exercice Exercice 1 (7 points) : effectifs
On a relevé le nombre d’enfants de $20$ familles : $0$ (×$2$), $1$ (×$5$), $2$ (×$8$), $3$ (×$4$), $4$ (×$1$).

1. Calculer les fréquences en pourcentage. (2 pts)
2. Calculer les effectifs cumulés croissants. (2 pts)
3. Calculer les angles du diagramme circulaire. (3 pts)

:::corrige
1. $10\,\%$ ; $25\,\%$ ; $40\,\%$ ; $20\,\%$ ; $5\,\%$.
2. $2$ ; $7$ ; $15$ ; $19$ ; $20$.
3. $36°$ ; $90°$ ; $144°$ ; $72°$ ; $18°$.
:::
:::

:::exercice Exercice 2 (7 points) : paramètres
Avec la même série :

1. Calculer le nombre moyen d’enfants par famille. (3 pts)
2. Déterminer la médiane. (2 pts)
3. Donner le mode et l’étendue. (2 pts)

:::corrige
1. $\frac{0 + 5 + 16 + 12 + 4}{20} = \frac{37}{20} = 1{,}85$.
2. Rangs $10$ et $11$ : les effectifs cumulés sont $2$, $7$, $15$…, donc ces rangs valent $2$ : $Me = 2$.
3. Mode $2$ ; étendue $4$.
:::
:::

:::exercice Exercice 3 (6 points) : une série en classes
Temps de travail quotidien de $20$ élèves, en heures : $[0 ; 1[$ : $4$ ; $[1 ; 2[$ : $10$ ; $[2 ; 3[$ : $6$.

1. Calculer le temps moyen, avec les centres des classes. (4 pts)
2. Quelle est la classe modale ? (2 pts)

:::corrige
1. $\frac{4 \times 0{,}5 + 10 \times 1{,}5 + 6 \times 2{,}5}{20} = \frac{2 + 15 + 15}{20} = 1{,}6$ heure.
2. $[1 ; 2[$.
:::
:::
