## Définition

:::definition
Pour un nombre $a \geq 0$, la **racine carrée** de $a$, notée $\sqrt{a}$, est le nombre **positif** dont le carré est égal à $a$.
:::

:::exemple
$\sqrt{49} = 7$ car $7^2 = 49$ et $7 \geq 0$ ; $\sqrt{0{,}25} = 0{,}5$ ; $\sqrt{\frac{9}{16}} = \frac{3}{4}$ ; $\sqrt{0} = 0$ ; $\sqrt{1} = 1$.
:::

:::attention
La racine carrée d’un nombre négatif n’existe pas : $\sqrt{-4}$ n’a pas de sens.
:::

## Carré d’une racine, racine d’un carré

:::propriete
- Pour $a \geq 0$ : $\left(\sqrt{a}\right)^2 = a$ et $\sqrt{a^2} = a$.
- Pour $a < 0$ : $\sqrt{a^2} = -a$. Par exemple $\sqrt{(-3)^2} = \sqrt{9} = 3$.
:::

:::exemple
$\left(\sqrt{7}\right)^2 = 7$ ; $\sqrt{5^2} = 5$ ; $\left(2\sqrt{3}\right)^2 = 4 \times 3 = 12$.
:::

## L’équation $x^2 = a$

:::propriete
- Si $a > 0$ : deux solutions, $\sqrt{a}$ et $-\sqrt{a}$.
- Si $a = 0$ : une solution, $0$.
- Si $a < 0$ : aucune solution, car un carré n’est jamais négatif.
:::

:::exemple
- $x^2 = 25 \iff x = 5$ ou $x = -5$.
- $x^2 = 7 \iff x = \sqrt{7}$ ou $x = -\sqrt{7}$.
- $x^2 = -4$ n’a pas de solution.
- $(x - 1)^2 = 9 \iff x - 1 = 3$ ou $x - 1 = -3 \iff x = 4$ ou $x = -2$.
:::
