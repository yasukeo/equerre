Trois exercices sur la première partie du cours.

:::exercice Calculer
Calculer : $\sqrt{81}$ ; $\sqrt{0{,}09}$ ; $\sqrt{\frac{25}{36}}$ ; $\sqrt{1{,}44}$.

:::corrige
$9$ ; $0{,}3$ ; $\frac{5}{6}$ ; $1{,}2$.
:::
:::

:::exercice Carrés et racines
Calculer : $\left(\sqrt{11}\right)^2$ ; $\sqrt{(-6)^2}$ ; $\left(2\sqrt{3}\right)^2$ ; $\left(-\sqrt{5}\right)^2$.

:::corrige
$11$ ; $6$ ; $12$ ; $5$.
:::
:::

:::exercice Équations
Résoudre :

1. $x^2 = 49$
2. $x^2 = 13$
3. $x^2 + 4 = 0$
4. $2x^2 = 50$
5. $(x - 1)^2 = 9$

:::corrige
1. $x = 7$ ou $x = -7$.
2. $x = \sqrt{13}$ ou $x = -\sqrt{13}$.
3. $x^2 = -4$ : aucune solution.
4. $x^2 = 25$ : $x = 5$ ou $x = -5$.
5. $x - 1 = \pm 3$ : $x = 4$ ou $x = -2$.
:::
:::
