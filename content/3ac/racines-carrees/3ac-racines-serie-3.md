:::exercice Problème 1 : un triangle rectangle
Un triangle $ABC$ est rectangle en $A$, avec $AB = \sqrt{5}$ cm et $AC = \sqrt{20}$ cm.

1. Simplifier $\sqrt{20}$.
2. Calculer $BC$.
3. Calculer l’aire du triangle.
4. Calculer son périmètre, sous la forme $a + b\sqrt{5}$.

:::corrige
1. $\sqrt{20} = 2\sqrt{5}$.
2. Pythagore : $BC^2 = 5 + 20 = 25$, donc $BC = 5$ cm.
3. $\frac{\sqrt{5} \times 2\sqrt{5}}{2} = \frac{10}{2} = 5$ cm².
4. $\sqrt{5} + 2\sqrt{5} + 5 = 5 + 3\sqrt{5}$ cm.
:::
:::

:::exercice Problème 2 : le nombre d’or
On pose $x = \dfrac{1 + \sqrt{5}}{2}$.

1. Calculer $x^2$.
2. Montrer que $x^2 = x + 1$.
3. Montrer que $\frac{1}{x} = \frac{\sqrt{5} - 1}{2}$, puis que $\frac{1}{x} = x - 1$.

:::corrige
1. $x^2 = \frac{1 + 2\sqrt{5} + 5}{4} = \frac{6 + 2\sqrt{5}}{4} = \frac{3 + \sqrt{5}}{2}$.
2. $x + 1 = \frac{1 + \sqrt{5}}{2} + \frac{2}{2} = \frac{3 + \sqrt{5}}{2} = x^2$.
3. $\frac{1}{x} = \frac{2}{1 + \sqrt{5}} = \frac{2\left(\sqrt{5} - 1\right)}{5 - 1} = \frac{\sqrt{5} - 1}{2}$, et $x - 1 = \frac{1 + \sqrt{5} - 2}{2} = \frac{\sqrt{5} - 1}{2}$.
:::
:::
