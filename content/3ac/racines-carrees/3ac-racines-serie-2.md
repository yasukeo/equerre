Quatre exercices sur la deuxième partie du cours.

:::exercice Simplifier
Écrire sous la forme $a\sqrt{b}$, avec $b$ le plus petit possible : $\sqrt{12}$ ; $\sqrt{45}$ ; $\sqrt{200}$ ; $\sqrt{98}$.

:::corrige
$2\sqrt{3}$ ; $3\sqrt{5}$ ; $10\sqrt{2}$ ; $7\sqrt{2}$.
:::
:::

:::exercice Sommes et produits
Calculer :

1. $2\sqrt{3} + \sqrt{27} - \sqrt{12}$
2. $\sqrt{2} \times \sqrt{18}$
3. $\sqrt{5} \times \sqrt{20}$
4. $3\sqrt{2} \times 2\sqrt{2}$

:::corrige
1. $2\sqrt{3} + 3\sqrt{3} - 2\sqrt{3} = 3\sqrt{3}$.
2. $\sqrt{36} = 6$.
3. $\sqrt{100} = 10$.
4. $6 \times 2 = 12$.
:::
:::

:::exercice Développer
Développer et réduire :

1. $\left(\sqrt{5} - 1\right)\left(\sqrt{5} + 1\right)$
2. $\left(1 + \sqrt{3}\right)^2$
3. $\left(2\sqrt{2} - 1\right)^2$

:::corrige
1. $5 - 1 = 4$.
2. $1 + 2\sqrt{3} + 3 = 4 + 2\sqrt{3}$.
3. $8 - 4\sqrt{2} + 1 = 9 - 4\sqrt{2}$.
:::
:::

:::exercice Dénominateurs
Écrire sans racine au dénominateur : $\dfrac{6}{\sqrt{2}}$ ; $\dfrac{5}{2\sqrt{5}}$ ; $\dfrac{1}{\sqrt{3} + 1}$.

:::corrige
- $\frac{6\sqrt{2}}{2} = 3\sqrt{2}$.
- $\frac{5\sqrt{5}}{10} = \frac{\sqrt{5}}{2}$.
- $\frac{\sqrt{3} - 1}{3 - 1} = \frac{\sqrt{3} - 1}{2}$.
:::
:::
