## Définition

:::propriete
- $\sqrt{a}$ ($a \geq 0$) : le nombre positif de carré $a$. $\left(\sqrt{a}\right)^2 = a$.
- $x^2 = a$ : deux solutions $\pm\sqrt{a}$ si $a > 0$ ; $0$ si $a = 0$ ; aucune si $a < 0$.
:::

## Calculs

:::propriete
- $\sqrt{ab} = \sqrt{a}\sqrt{b}$ ; $\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$.
- Simplifier : $\sqrt{18} = 3\sqrt{2}$ (chercher un carré parfait).
- $\frac{a}{\sqrt{b}} = \frac{a\sqrt{b}}{b}$ ; avec $\sqrt{b} - c$, multiplier par $\sqrt{b} + c$.
:::

:::attention
$\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}$.
:::
