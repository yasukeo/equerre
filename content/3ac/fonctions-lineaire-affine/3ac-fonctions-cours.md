## Définition

:::definition
Soit $a$ un nombre. La fonction qui à tout nombre $x$ associe $ax$ est la **fonction linéaire** de **coefficient** $a$. On écrit $f : x \mapsto ax$, ou $f(x) = ax$.
:::

:::exemple
$f(x) = -3x$ : l’image de $2$ est $f(2) = -6$. L’antécédent de $12$ est le nombre $x$ tel que $-3x = 12$, soit $x = -4$.
:::

## Trouver le coefficient

:::propriete
Si $f$ est linéaire et $x \neq 0$, alors $a = \frac{f(x)}{x}$.
:::

:::exemple
$f$ est linéaire et $f(5) = 15$ : $a = \frac{15}{5} = 3$, donc $f(x) = 3x$, et $f(10) = 30$.
:::

## Représentation graphique

:::propriete
Dans un repère, la représentation graphique d’une fonction linéaire est une **droite qui passe par l’origine**. Le coefficient $a$ est sa pente.
:::

:::exemple
Pour tracer $f(x) = 1{,}5x$, on place l’origine et le point $(2 ; 3)$, car $f(2) = 3$. Le point $(4 ; 6)$ est sur la droite, car $f(4) = 6$ ; le point $(-2 ; 3)$ n’y est pas, car $f(-2) = -3$.
:::

## Proportionnalité et pourcentages

:::propriete
- Une fonction linéaire traduit une situation de **proportionnalité**.
- Augmenter de $t\,\%$, c’est appliquer la fonction linéaire $x \mapsto \left(1 + \frac{t}{100}\right)x$ ; diminuer de $t\,\%$, c’est appliquer $x \mapsto \left(1 - \frac{t}{100}\right)x$.
:::

:::exemple
- Une hausse de $15\,\%$ : $x \mapsto 1{,}15x$. Un prix de $200$ dirhams devient $230$ dirhams.
- Une baisse de $20\,\%$ : $x \mapsto 0{,}8x$. Un prix de $350$ dirhams devient $280$ dirhams.
:::

:::attention
La représentation d’une fonction linéaire passe toujours par l’origine : $f(0) = 0$.
:::
