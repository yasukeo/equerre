## Fonction linéaire

:::propriete
- $f(x) = ax$ ; $a = \frac{f(x)}{x}$ pour $x \neq 0$.
- Droite passant par l’origine ; proportionnalité.
- Hausse de $t\,\%$ : $\times\left(1 + \frac{t}{100}\right)$ ; baisse : $\times\left(1 - \frac{t}{100}\right)$.
:::

## Fonction affine

:::propriete
- $f(x) = ax + b$ ; $b = f(0)$.
- $a = \frac{f(x_2) - f(x_1)}{x_2 - x_1}$, puis $b$ avec une valeur connue.
- Droite qui coupe l’axe des ordonnées en $(0 ; b)$, de pente $a$.
:::

:::attention
Image de $3$ : on calcule $f(3)$. Antécédent de $3$ : on résout $f(x) = 3$.
:::
