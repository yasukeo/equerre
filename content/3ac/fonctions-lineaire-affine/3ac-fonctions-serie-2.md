Quatre exercices sur la deuxième partie du cours.

:::exercice Images et antécédents
Soit $g(x) = -2x + 5$. Calculer $g(0)$ et $g(3)$, puis l’antécédent de $9$.

:::corrige
$g(0) = 5$ ; $g(3) = -1$ ; $-2x + 5 = 9 \iff x = -2$.
:::
:::

:::exercice Trouver une fonction affine
1. $f$ est affine, $f(1) = 4$ et $f(3) = 10$. Trouver $f(x)$.
2. $h$ est affine, $h(-2) = 7$ et $h(2) = -1$. Trouver $h(x)$.

:::corrige
1. $a = \frac{10 - 4}{2} = 3$ et $b = 1$ : $f(x) = 3x + 1$.
2. $a = \frac{-1 - 7}{2 - (-2)} = -2$ ; $-1 = -4 + b$, donc $b = 3$ : $h(x) = -2x + 3$.
:::
:::

:::exercice Linéaire, affine ou ni l’un ni l’autre ?
$f(x) = 5x$ ; $g(x) = 2x + 1$ ; $h(x) = x^2$ ; $k(x) = 7$.

:::corrige
$f$ est linéaire (donc aussi affine) ; $g$ est affine ; $h$ n’est ni linéaire ni affine ; $k$ est affine constante ($a = 0$, $b = 7$).
:::
:::

:::exercice Lire une droite
Une droite passe par les points $(0 ; 2)$ et $(3 ; 8)$. De quelle fonction affine est-elle la représentation ?

:::corrige
$b = 2$ et $a = \frac{8 - 2}{3 - 0} = 2$ : $x \mapsto 2x + 2$.
:::
:::
