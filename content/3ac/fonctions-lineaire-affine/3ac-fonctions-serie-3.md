:::exercice Problème 1 : deux tarifs
Une bibliothèque propose deux tarifs : tarif A, $15$ dirhams par livre emprunté ; tarif B, un abonnement de $60$ dirhams puis $5$ dirhams par livre.

1. Exprimer le prix $A(x)$ et le prix $B(x)$ pour $x$ livres. Quelle fonction est linéaire ?
2. Calculer les deux prix pour $4$ livres, puis pour $10$ livres.
3. Pour combien de livres les deux tarifs sont-ils égaux ?
4. Quel tarif conseiller à un lecteur qui emprunte $8$ livres par an ?

:::corrige
1. $A(x) = 15x$ (linéaire) et $B(x) = 5x + 60$ (affine).
2. $4$ livres : $A = 60$, $B = 80$. $10$ livres : $A = 150$, $B = 110$.
3. $15x = 5x + 60 \iff x = 6$.
4. $A(8) = 120$ et $B(8) = 100$ : le tarif B.
:::
:::

:::exercice Problème 2 : Celsius et Fahrenheit
La température $F$ en degrés Fahrenheit s’obtient à partir de la température $C$ en degrés Celsius par $F = 1{,}8C + 32$.

1. Cette fonction est-elle linéaire ? affine ?
2. Convertir $25$ °C en degrés Fahrenheit.
3. L’eau bout à $212$ °F. Quelle est cette température en degrés Celsius ?
4. Pour quelle température les deux nombres sont-ils égaux ?

:::corrige
1. Affine ($a = 1{,}8$, $b = 32$), mais pas linéaire car $b \neq 0$.
2. $1{,}8 \times 25 + 32 = 77$ °F.
3. $1{,}8C + 32 = 212 \iff 1{,}8C = 180 \iff C = 100$ °C.
4. $C = 1{,}8C + 32 \iff -0{,}8C = 32 \iff C = -40$ : $-40$ °C $= -40$ °F.
:::
:::
