## Relations trigonométriques

:::propriete
Pour tout angle aigu $x$ :

$$
\cos^2 x + \sin^2 x = 1 \qquad \tan x = \frac{\sin x}{\cos x}
$$
:::

En effet, dans le triangle rectangle, $\cos^2 x + \sin^2 x = \frac{AB^2 + AC^2}{BC^2} = 1$ d’après le théorème de Pythagore.

:::exemple
Si $x$ est aigu et $\sin x = \frac{3}{5}$ : $\cos^2 x = 1 - \frac{9}{25} = \frac{16}{25}$, et $\cos x > 0$, donc $\cos x = \frac{4}{5}$ et $\tan x = \frac{3/5}{4/5} = \frac{3}{4}$.
:::

## Angles complémentaires

:::propriete
Si $x$ et $y$ sont complémentaires ($x + y = 90°$), alors $\sin x = \cos y$, $\cos x = \sin y$ et $\tan x \times \tan y = 1$.
:::

:::exemple
$\sin 20° = \cos 70°$, donc $\sin 20° - \cos 70° = 0$ ; et $\tan 40° \times \tan 50° = 1$.
:::

## Valeurs remarquables

:::propriete
- $\cos 30° = \frac{\sqrt{3}}{2}$, $\sin 30° = \frac{1}{2}$, $\tan 30° = \frac{\sqrt{3}}{3}$.
- $\cos 45° = \sin 45° = \frac{\sqrt{2}}{2}$, $\tan 45° = 1$.
- $\cos 60° = \frac{1}{2}$, $\sin 60° = \frac{\sqrt{3}}{2}$, $\tan 60° = \sqrt{3}$.
:::

:::exemple
$2\sin 30° + \cos 60° = 1 + \frac{1}{2} = \frac{3}{2}$ ; $\tan 60° \times \tan 30° = \sqrt{3} \times \frac{\sqrt{3}}{3} = 1$.
:::

:::attention
$\cos^2 x$ signifie $(\cos x)^2$, et non $\cos(x^2)$.
:::
