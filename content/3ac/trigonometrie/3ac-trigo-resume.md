## Définitions

:::propriete
- $\cos = \frac{\text{adjacent}}{\text{hypoténuse}}$ ; $\sin = \frac{\text{opposé}}{\text{hypoténuse}}$ ; $\tan = \frac{\text{opposé}}{\text{adjacent}}$.
- Pour un angle : touches $\cos^{-1}$, $\sin^{-1}$, $\tan^{-1}$, calculatrice en degrés.
:::

## Relations

:::propriete
- $\cos^2 x + \sin^2 x = 1$ ; $\tan x = \frac{\sin x}{\cos x}$.
- $x + y = 90°$ : $\sin x = \cos y$ et $\tan x \times \tan y = 1$.
- $30°$ : $\left(\frac{\sqrt{3}}{2} ; \frac{1}{2}\right)$ ; $45°$ : $\left(\frac{\sqrt{2}}{2} ; \frac{\sqrt{2}}{2}\right)$ ; $60°$ : $\left(\frac{1}{2} ; \frac{\sqrt{3}}{2}\right)$ (cosinus ; sinus).
:::

:::attention
Le cosinus et le sinus d’un angle aigu sont entre $0$ et $1$.
:::
