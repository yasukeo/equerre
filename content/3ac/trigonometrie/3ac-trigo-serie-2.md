Quatre exercices sur la deuxième partie du cours.

:::exercice Du cosinus au sinus
$x$ est un angle aigu tel que $\cos x = 0{,}8$. Calculer $\sin x$ et $\tan x$.

:::corrige
$\sin^2 x = 1 - 0{,}64 = 0{,}36$ et $\sin x > 0$ : $\sin x = 0{,}6$, puis $\tan x = \frac{0{,}6}{0{,}8} = 0{,}75$.
:::
:::

:::exercice Simplifier
Calculer sans calculatrice :

1. $A = \cos^2 35° + \sin^2 35°$
2. $B = \sin 25° - \cos 65°$
3. $C = \tan 40° \times \tan 50°$
4. $D = \cos^2 20° + \cos^2 70°$

:::corrige
1. $1$.
2. $25° + 65° = 90°$, donc $\sin 25° = \cos 65°$ : $B = 0$.
3. Angles complémentaires : $C = 1$.
4. $\cos 70° = \sin 20°$, donc $D = \cos^2 20° + \sin^2 20° = 1$.
:::
:::

:::exercice Valeurs exactes
Calculer : $E = 2\sin 30° + \cos 60°$ ; $F = \sin 45° \times \cos 45°$ ; $G = \tan 60° \times \tan 30°$.

:::corrige
$E = 1 + \frac{1}{2} = \frac{3}{2}$ ; $F = \frac{\sqrt{2}}{2} \times \frac{\sqrt{2}}{2} = \frac{1}{2}$ ; $G = \sqrt{3} \times \frac{\sqrt{3}}{3} = 1$.
:::
:::

:::exercice Une identité
Montrer que pour tout angle aigu $x$ : $(\cos x + \sin x)^2 = 1 + 2\sin x \cos x$.

:::corrige
$(\cos x + \sin x)^2 = \cos^2 x + 2\sin x \cos x + \sin^2 x = 1 + 2\sin x \cos x$.
:::
:::
