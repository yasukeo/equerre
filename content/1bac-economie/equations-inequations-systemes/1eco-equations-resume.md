## Second degré

:::propriete
- $\Delta = b^2 - 4ac$. Si $\Delta > 0$ : $x = \frac{-b \pm \sqrt{\Delta}}{2a}$ ; si $\Delta = 0$ : $x_0 = -\frac{b}{2a}$ ; si $\Delta < 0$ : pas de solution.
- $x_1 + x_2 = -\frac{b}{a}$ et $x_1 x_2 = \frac{c}{a}$.
- Signe : celui de $a$, sauf entre les racines.
:::

## Systèmes

:::propriete
- Deux équations : $D = ab' - a'b$ ; si $D \neq 0$, $x = \frac{D_x}{D}$ et $y = \frac{D_y}{D}$.
- Trois équations : éliminer une inconnue avec une équation pivot, puis résoudre le système de deux équations.
- $ax + by + c \leq 0$ : un demi-plan limité par la droite $ax + by + c = 0$ ; on teste l’origine.
:::

:::attention
Dans une équation avec fraction ou racine, on fixe d’abord le domaine, puis on vérifie que les solutions trouvées y sont.
:::
