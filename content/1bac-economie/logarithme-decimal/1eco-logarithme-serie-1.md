Trois exercices sur la première partie du cours.

:::exercice Sans calculatrice
Calculer :

1. $\log 1\,000$, $\log 0{,}01$ et $\log \sqrt{10}$
2. $\log\left(10^5 \times 0{,}001\right)$
3. $\log 25 + \log 4$
4. $\log 50 - \log 5$

:::corrige
1. $3$, $-2$ et $\frac{1}{2}$.
2. $10^5 \times 10^{-3} = 10^2$ : $2$.
3. $\log 100 = 2$.
4. $\log 10 = 1$.
:::
:::

:::exercice Avec log 2 et log 3
On pose $a = \log 2$ et $b = \log 3$. Exprimer en fonction de $a$ et $b$ :

1. $\log 6$, $\log 18$ et $\log 1{,}5$
2. $\log 5$ et $\log 45$
3. $\log 0{,}24$

:::corrige
1. $\log 6 = a + b$ ; $\log 18 = \log(2 \times 3^2) = a + 2b$ ; $\log 1{,}5 = \log \frac{3}{2} = b - a$.
2. $\log 5 = \log \frac{10}{2} = 1 - a$ ; $\log 45 = \log(3^2 \times 5) = 2b + 1 - a$.
3. $0{,}24 = \frac{2^3 \times 3}{100}$, donc $\log 0{,}24 = 3a + b - 2$.
:::
:::

:::exercice Simplifier
Simplifier :

1. $A = 2\log 5 + \log 4$
2. $B = \log\left(\sqrt{2} + 1\right) + \log\left(\sqrt{2} - 1\right)$
3. $C = 3\log 2 + \log 125 - \log 0{,}1$

:::corrige
1. $A = \log 25 + \log 4 = \log 100 = 2$.
2. $B = \log\left((\sqrt{2} + 1)(\sqrt{2} - 1)\right) = \log(2 - 1) = \log 1 = 0$.
3. $3\log 2 + \log 125 = \log(8 \times 125) = \log 1\,000 = 3$, et $\log 0{,}1 = -1$ : $C = 3 + 1 = 4$.
:::
:::
