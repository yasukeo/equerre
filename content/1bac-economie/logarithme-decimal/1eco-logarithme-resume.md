## Définition et propriétés

:::propriete
- Pour $x > 0$ : $y = \log x \iff x = 10^y$. $\log 1 = 0$, $\log 10 = 1$, $\log 10^n = n$.
- $\log(ab) = \log a + \log b$, $\log \frac{a}{b} = \log a - \log b$, $\log a^n = n\log a$, $\log \sqrt{a} = \frac{1}{2}\log a$.
- $\log$ est strictement croissante : $\log a < \log b \iff a < b$ ; $\log x > 0 \iff x > 1$.
:::

## Méthodes

- Équation ou inéquation : domaine d’abord, puis $\log A = \log B \iff A = B$.
- Exposant inconnu : $a^n \geq b \iff n\log a \geq \log b$ ; attention au sens si $\log a < 0$.
- Nombre de chiffres de $N$ : le $k$ tel que $k - 1 \leq \log N < k$.

:::attention
$\log(a + b) \neq \log a + \log b$, et $\log x$ n’existe que pour $x > 0$.
:::
