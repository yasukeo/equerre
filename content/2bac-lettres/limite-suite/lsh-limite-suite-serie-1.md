Trois exercices sur la première partie du cours.

:::exercice Opérations
Calculer la limite de chaque suite.

1. $u_n = 5 - \dfrac{3}{n}$ ($n \geq 1$)
2. $v_n = 2n^2 + n + 1$
3. $w_n = -n^3 + 4$
4. $t_n = \dfrac{7}{n^2 + 1}$

:::corrige
1. $\frac{3}{n} \to 0$, donc $u_n \to 5$.
2. Somme de termes qui tendent vers $+\infty$ (et de $1$) : $+\infty$.
3. $-n^3 \to -\infty$ : $-\infty$.
4. $n^2 + 1 \to +\infty$ : $t_n \to 0$.
:::
:::

:::exercice Formes indéterminées
Calculer la limite de chaque suite.

1. $u_n = n^2 - 10n$
2. $v_n = 3n - n^2$
3. $w_n = n - \sqrt{n}$

:::corrige
1. $u_n = n^2\left(1 - \frac{10}{n}\right) \to +\infty$.
2. $v_n = n^2\left(\frac{3}{n} - 1\right) \to -\infty$.
3. $w_n = \sqrt{n}\left(\sqrt{n} - 1\right) \to +\infty$.
:::
:::

:::exercice Fractions
Calculer la limite de chaque suite.

1. $u_n = \dfrac{4n - 1}{2n + 5}$
2. $v_n = \dfrac{n^2 + 1}{3n^2 - n}$ ($n \geq 1$)
3. $w_n = \dfrac{5n}{n^2 + 2}$
4. $t_n = \dfrac{n^2}{n + 1}$

:::corrige
1. $\frac{4n}{2n} = 2$ : la limite vaut $2$.
2. $\frac{n^2}{3n^2} = \frac{1}{3}$.
3. $\frac{5n}{n^2} = \frac{5}{n} \to 0$.
4. $\frac{n^2}{n} = n \to +\infty$.
:::
:::
