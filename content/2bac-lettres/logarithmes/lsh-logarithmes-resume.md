## Définition

$\ln$ est définie sur $]0 ; +\infty[$, strictement croissante ; $\ln 1 = 0$, $\ln e = 1$ ; $\ln x > 0 \iff x > 1$.

## Règles

:::propriete
$\ln(ab) = \ln a + \ln b$ ; $\ln\frac{a}{b} = \ln a - \ln b$ ; $\ln\frac{1}{a} = -\ln a$ ; $\ln(a^n) = n\ln a$ ; $\ln\sqrt{a} = \frac{1}{2}\ln a$.
:::

## Équations et inéquations

Domaine d’abord (ce qui est dans $\ln$ est $> 0$), puis $\ln A = \ln B \iff A = B$, $\ln A < \ln B \iff A < B$. $\ln x = k \iff x = e^k$.

## Limites et dérivée

:::propriete
- $\ln x \to +\infty$ en $+\infty$, $\ln x \to -\infty$ en $0^+$.
- $\frac{\ln x}{x} \to 0$ en $+\infty$ ; $x\ln x \to 0$ en $0^+$.
- $(\ln x)' = \frac{1}{x}$.
:::

:::attention
$\ln(a + b) \neq \ln a + \ln b$, et une solution doit toujours être vérifiée dans le domaine.
:::
