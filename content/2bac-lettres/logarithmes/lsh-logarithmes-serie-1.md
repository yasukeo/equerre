Quatre exercices sur la première partie du cours.

:::exercice Simplifier
Écrire en fonction de $\ln 2$ et $\ln 3$ :

$$
A = \ln 12 \qquad B = \ln\frac{8}{9} \qquad C = \ln 36 - \ln 4 \qquad D = \ln\sqrt{6}
$$

:::corrige
- $A = \ln(4 \times 3) = 2\ln 2 + \ln 3$.
- $B = 3\ln 2 - 2\ln 3$.
- $C = \ln 9 = 2\ln 3$.
- $D = \frac{1}{2}(\ln 2 + \ln 3)$.
:::
:::

:::exercice Calculer avec e
Calculer :

$$
A = \ln\left(e^4\right) \qquad B = \ln\frac{1}{e} \qquad C = \ln\left(e^2\right) - \ln\sqrt{e} \qquad D = 3\ln e - \ln 1
$$

:::corrige
$A = 4$, $B = -1$, $C = 2 - \frac{1}{2} = \frac{3}{2}$, $D = 3$.
:::
:::

:::exercice Ensembles de définition
Pour quelles valeurs de $x$ les expressions suivantes ont-elles un sens ?

1. $\ln(x - 3)$
2. $\ln(5 - 2x)$
3. $\ln(x^2 + 1)$

:::corrige
1. $x > 3$.
2. $5 - 2x > 0 \iff x < \frac{5}{2}$.
3. $x^2 + 1 > 0$ pour tout $x$ : pour tout réel $x$.
:::
:::

:::exercice Équations et inéquations
Résoudre :

1. $\ln(x + 2) = \ln(3x - 4)$
2. $\ln x = -3$
3. $\ln(2x) \geq \ln 8$
4. $\ln(x - 1) < 0$

:::corrige
1. Domaine : $x > \frac{4}{3}$. $x + 2 = 3x - 4 \iff x = 3$, qui convient : $S = \{3\}$.
2. $x = e^{-3}$.
3. Domaine : $x > 0$. $2x \geq 8 \iff x \geq 4$ : $S = [4 ; +\infty[$.
4. Domaine : $x > 1$. $\ln(x - 1) < \ln 1 \iff x - 1 < 1 \iff x < 2$ : $S = ]1 ; 2[$.
:::
:::
