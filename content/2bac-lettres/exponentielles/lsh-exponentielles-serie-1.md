Trois exercices sur la première partie du cours.

:::exercice Simplifier
Simplifier :

$$
A = e^4 \times e^{-2} \qquad B = \frac{e^7}{e^3} \qquad C = \left(e^{-1}\right)^4 \times e^5 \qquad D = e^{\ln 4} + e^{-\ln 2}
$$

:::corrige
$A = e^2$, $B = e^4$, $C = e^{-4 + 5} = e$, $D = 4 + \frac{1}{2} = \frac{9}{2}$.
:::
:::

:::exercice Équations
Résoudre dans $\mathbb{R}$ :

1. $e^{3x + 1} = e^{x - 5}$
2. $e^x = 10$
3. $e^{2x} = 1$
4. $e^x + 3 = 0$

:::corrige
1. $3x + 1 = x - 5 \iff x = -3$.
2. $x = \ln 10$.
3. $2x = 0 \iff x = 0$.
4. $e^x = -3$ : aucune solution.
:::
:::

:::exercice Inéquations
Résoudre dans $\mathbb{R}$ :

1. $e^{x - 2} > 1$
2. $e^{2x} \leq e^{x + 1}$
3. $e^x < 5$

:::corrige
1. $x - 2 > 0 \iff x > 2$.
2. $2x \leq x + 1 \iff x \leq 1$.
3. $x < \ln 5$.
:::
:::
